旧小主机放在家里：自动化、存储还是媒体？

先选一个明确用途，再检查启动方式、存储健康和备份。安装系统并不自动增加算力。

家庭自动化

  • HAOS 适合可专用的 x86-64 UEFI 主机。官方 Generic 路径要求关闭 Secure Boot，并核对 512n/512e；不能只看 64 位 CPU。
  • 写入会覆盖目标磁盘。连接一个真实设备并演练备份恢复后，再考虑长期使用。

局域网存储

  • OpenMediaVault 需要规划系统盘、数据盘和独立备份；旧硬盘健康是单独的问题。
  • README 说明系统需要独占 OS 配置，不应将它当作可任意容器化或并装桌面的普通应用。RAID 不替代备份。

轻量服务、影音或游戏

  • DietPi 先检查目标设备是否有映像、架构与 RAM 是否满足；不保证任意旧板都适配。
  • LibreELEC 是专用 Kodi 系统，需要当前映像与硬件匹配；DRM 服务另行核查。
  • Batocera 可考虑外置启动，内部安装前仍需备份；性能受硬件限制，系统不提供游戏版权授权。

选择时记录什么

  • 启动方式、磁盘逻辑扇区、网络与外设支持，以及重启后的状态。
  • 电力、噪声、磁盘与附件支出由实际设备决定，本目录没有测量值或价格。
  • 先用外置介质或备份降低切换成本；以下链接提供各路线的原始文档和限制。
