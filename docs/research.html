候选与空白

  • postmarketOS / current site migration — 旧 pmaports GitHub 地址不可用；下载页本轮重定向至 nura.eco。需沿官方迁移公告核对代码仓库、许可、型号矩阵后入主目录，不能以旧品牌记忆替代当前来源。
  • Libreboot — 官方 Git 页确认源码在 Codeberg；本轮未完成目标板恢复与许可证逐项核验，不采用不存在的 GitHub 镜像。
  • Debian on Kirkwood NAS — 须从维护者原始教程核对具体 NAS、U-Boot、内核和串口恢复；本轮未完成，不能把泛泛旧 NAS 教程当成成品项目。
  • Rebble Web Services — 官方 HOWTO 与设置页已读取，确认替代 Pebble 停服后的部分服务；尚未逐项核对当前手机配套应用、固件与服务许可证，作为优先补全候选。
  • AI 辅助 HP BIOS 修改案例 — 目前只有报道线索，缺少本轮确认的作者源码、版本、备份/恢复和独立复现；不收录为成功项目。
  • 新购 ESP32 AI 玩具套件 — 优秀 AI 工程不自动等于旧硬件复活；需要指向具体闲置成品硬件复用案例，才新增条目。

本轮缺少长期稳定性、能耗、实际费用与独立硬件复现；旧 NAS、当前手机镜像与停服穿戴服务需继续补全。未声称覆盖全网。
