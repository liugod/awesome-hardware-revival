Start with the pilot: Nest Mini local AI

For a second-generation Nest Mini, the realistic route is not a jailbreak of Google’s stock firmware. An Onju ESP32-S3 board replaces the original board and turns the enclosure, microphones, speaker, and touch controls into a network endpoint. ASR, the LLM, and TTS run on a LAN host or optional cloud service.
