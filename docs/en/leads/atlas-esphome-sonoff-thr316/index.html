Exact-model review

  • Hardware ESP32 with one relay, three LEDs, button and RJ9 bus for an external DS18B20 sensor.
  • Installation route Use the documented GPIO and RJ9 pinout to combine the temperature sensor and relay as a Home Assistant thermostat.
  • Expected result Monitors temperature locally and switches a heating load around a set point.
  • Boundary The example assumes DS18B20; other temperature/humidity probes and THR316D are not drop-in equivalents.
  • Recovery and stop condition Keep the relay off at boot and validate sensor readings plus short/long button behavior before connecting a real load.
