EXACT-MODEL SOURCE REVIEWED

Hardware

HK1 Box listed by ophub under Amlogic S905X3 on the stable-kernel route.

Installation route

Boot from USB/microSD and verify the meson-sm1-hk1box-vontar-x3 device tree before considering eMMC installation.

Expected result

Can serve as a small Armbian host; the linked report also discusses LED display and fan GPIO.

Boundary

Fan, display, network and board variants exist under the same name; issue 414 concerns a specific acrylic fan model.

Recovery and stop condition Save the Android image and boot partitions and require stable external boot before eMMC; stop on fan failure or unsafe temperature.
