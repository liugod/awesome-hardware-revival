Shelly Plus i4: convert it to a local ESPHome device

The goal is clear: use an ESPHome configuration for Shelly Plus i4, reduce dependence on the vendor cloud and connect it to a local system such as Home Assistant.

D068 · E1 · Sources reviewed 2026-10-22 · No hands-on hardware tests

EXACT-MODEL SOURCE REVIEWED

Hardware

Single-core ESP32-U4WDH, 4 MB flash and four wall-switch inputs.

Installation route

Run ESPHome with ESP-IDF single-core settings and map single, double and long presses to Home Assistant events.

Expected result

Turns four physical switches into local automation inputs without directly switching loads.

Boundary

This is an input module, not a four-relay controller; initial flashing needs separate confirmation.

Recovery and stop condition Validate all inputs under low-voltage programming conditions and never treat input terminals as relay outputs.
