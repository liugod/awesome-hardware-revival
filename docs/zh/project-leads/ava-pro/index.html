开始前的三点

  • 你需要什么 Android 5.0/API 21 以上的 arm64-v8a 或 armeabi-v7a 设备，至少 1 GB 内存与 100 MB 空间；已运行并装好 ESPHome 集成的 Home Assistant；两者在同一局域网，且能授予麦克风、悬浮窗和前台服务权限。教程 1 ↗ · 教程 2 ↗
  • 大致步骤 安装 APK 并授予必需权限；在 Home Assistant 添加 ESPHome；到 Ava 的 Voice Config 启动服务，在 HA 配置发现的设备，选择语音管线和唤醒词，确认状态为 Connected。自动发现失败时，手动填入设备 IP 与 Add this device 卡片显示的实际端口。教程 1 ↗
  • 何时停止 Android 版本或 CPU 架构不支持、无法授予必需权限、设备与 HA 不在同一局域网，或服务实际端口不可达时停止；手动 IP+端口仍连不上时，不要继续配置可选功能。教程 1 ↗ · 教程 2 ↗
