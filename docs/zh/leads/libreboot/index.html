是否值得继续

  • 当前阶段 上游项目与文档较完整，存在明确支持设备和安装路线；KitAgain 尚未整理全部板号。
  • 现在能用到什么程度 当前官方清单中的准确主板可进入安装评估；部分可内部刷写，部分必须使用外置编程器。
  • 用户价值 支持清单足以帮助用户判断板号、刷写方式和恢复工具；主要不确定性是固件写入风险。
  • 继续跟进建议 能确认主板、完整备份闪存并准备恢复工具时继续；无法承担变砖风险时不要开始。

适用设备与限制

已知可参考或可继续核查

  • 官方列出的 ThinkPad X200/T400/T500/W500/R400/R500
  • 官方列出的 X220/X220T/T420/T420s/T520 与 X230/T430/T530/W530/X230T 路线
  • 当前支持清单中的特定 Chromebook、服务器、台式机和工作站板号

不能视为已支持

  • 同系列但未出现在当前支持清单的主板修订
  • 已移除板卡或只有旧教程、没有当前 ROM 的设备
  • 无法确认闪存芯片、备份和外部恢复条件的机器

缺口、下一步与风险

  • 为什么仍是 E0 项目资料较完整，但 KitAgain 尚未把支持主板、内部/外部刷写条件、许可证范围和恢复设备逐项整理成正式条目。
  • 下一步核验 从一个具体 ThinkPad 或 Chromebook 板号开始，核对 ROM、刷写方式、备份和回退。
  • 风险与停止条件 这是固件写入操作。官方要求先备份当前闪存，并明确警告错误操作可能导致设备无法启动。

链接里分别有什么

  • 官方支持清单与安装文档 ↗official-support-and-install
    列出支持设备、各主板安装入口、内部/外部刷写和安全警告，应从这里确认准确板号。https://libreboot.org/docs/install/
  • lbmk 构建系统 ↗build-system
    用于获取和构建源码与镜像；适合核对构建流程，不是兼容清单。https://codeberg.org/libreboot/lbmk
  • 官方代码仓库索引 ↗repository-map
    解释项目代码分别存放在哪里，用于确认上游仓库与镜像关系。https://libreboot.org/git.html
