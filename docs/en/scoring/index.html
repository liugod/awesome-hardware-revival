1–5 review-maturity score

Evidence-capped, explainable for every entry, and fully exportable.

What the score answers

It answers how far KitAgain has reviewed the record—not how good the project is, whether it will work, or whether the procedure is safe.

Five evidence-capped levels

ScoreMeaningCurrent entries
1/5Only a public index or repository metadata was checked; still an E0 discovery lead.341
2/5A source page or decision sheet was read, but compatibility/deployment evidence remains insufficient; still E0.123
3/5Deployment, configuration, or exact-model material was read (E1); this is not a hands-on success.80
4/5E1 plus a specific author hardware claim or demonstration description (E2).3
5/5A traceable independent reproduction was verified (E3); currently zero entries.0

Calculation

Four auditable components are weighted: evidence strength 50%, source specificity 20%, recovery clarity 20%, and maintenance visibility 10%. A hard ceiling then applies: E0≤2, E1≤3, E2≤4, E3≤5. An E0 based only on an index or repository metadata is fixed at 1; an E0 with a source page or complete decision sheet can reach at most 2.

What is deliberately excluded

  • Stars, likes, views, and search popularity
  • Unverified success rates or compatibility promises
  • Treating unarchived/recently pushed as proof of usability
  • Counting multiple device models as independent projects
