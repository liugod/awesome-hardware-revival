动手之前

先做三个判断。

  1. 型号对得上吗？核对代际、区域、固件和板型；同名设备也可能不同。
  2. 来源说了什么？区分安装文档、作者实机和独立复现，不把演示当普遍兼容。
  3. 什么时候停？先确认回退方式；遇到未知板型、不可恢复步骤或不明供电就暂停。
