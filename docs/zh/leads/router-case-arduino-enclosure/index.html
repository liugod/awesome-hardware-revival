是否值得继续

  • 当前阶段 作者复用故障 Thomson TG585 路由器外壳、开关、LED 和电源接口，装入自制家居自动化原型。
  • 现在能用到什么程度 可快速得到带指示灯、按钮和易开盖的低压项目外壳。
  • 用户价值 低难度复用外壳和人机接口，适合大量常见电子废件。
  • 继续跟进建议 确认低压与绝缘后值得做；原路由器还能修复时优先修复整机。

适用设备与限制

已知可参考或可继续核查

  • 故障但外壳完整的低压路由器
  • Arduino、传感器或门铃接口等低压原型

不能视为已支持

  • 希望继续使用原路由器网络功能
  • 把未知原电源板直接接入新项目

缺口、下一步与风险

  • 为什么仍是 E0 主要复用机械与简单元件，不是复活路由器主板；不同外壳的 PCB、绝缘和固定方式需重新设计。
  • 下一步核验 确认原电源接口极性、LED 限流、板卡固定、开孔和长期电池/供电方案。
  • 风险与停止条件 必须完全移除或隔离未知原电源电路，避免松动板卡短路。
