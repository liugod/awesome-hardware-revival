计算方式

四个可审计分项先按证据强度 50%、来源具体性 20%、恢复说明 20%、维护信息可见度 10% 加权。随后应用硬上限：E0≤2、E1≤3、E2≤4、E3≤5。只有索引或仓库元数据的 E0 固定为 1；已有来源页或完整判断表的 E0 最多为 2。

不会进入评分的因素

  • star、点赞、浏览量和搜索热度
  • 未经核实的“成功率”和兼容承诺
  • 项目未归档或最近 push 被当成可用证明
  • 重复型号数量被当成多个独立项目
