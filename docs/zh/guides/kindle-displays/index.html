旧 Kindle 做信息屏：先选内容，再核对固件

Home Assistant、WHOOP 和桌面用量看板需要不同的外部服务。墨水屏是显示端，不能据此判断设备在本地运行 AI。

先检查手里的设备

  • 记下准确型号和固件，先查相应 jailbreak 指南；WinterBreak 是前置工具，不是成品看板。
  • Kindle 4 的 HA 示例不能证明任意 Paperwhite 可用；WHOOP 作者验证范围是 PW2 / 5.10.3。
  • 先保存设备文件与配置备份，明确移除脚本与撤销 jailbreak 是不同步骤。

按内容选择路线

  • 已有 Home Assistant：查看服务端截图＋Kindle 显示的路线，分别排查页面权限、截图和拉取。
  • 已有 WHOOP 数据：查看账户/API、KUAL/linkss 与唤醒链路；一次周期成功不代表数周续航。
  • 桌面 AI 工具用量：Kindle Dashboard 需要 Windows 10/11 主机及 SSH/FBInk；显示用量不等于运行模型。
  • 想切换多类内容：Kindle Carousel 的文档以 Kindle 3 / 4 NT 为范围，持续按键监听会影响续航。

开始前的最低验证

  • 先手动显示一张正确尺寸的图，再安排刷新和唤醒。
  • 模拟断网、认证失效和数据过期，避免屏幕静默展示旧状态。
  • 记录数日耗电、刷新失败与恢复；额外主机和服务尚未核价。以下项目页保留原始依据，本专题没有新增硬件实测。
