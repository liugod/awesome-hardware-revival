Why it remains E0

KitAgain has not checked code licensing, audio quality, latency, supply noise, amplifier inputs or long-term maintenance.

Next review step

Verify pinouts, BOM and licenses for both board variants, then run a reversible test through a stereo line input.

Risk and stop condition

Prefer an external low-voltage line input. Any internal mains wiring requires separate isolation and electrical-safety review.
