Three checks before starting

  • What you need An Android 8.0+ tablet, the target URL or app, and a 4–6 digit PIN. Full-lockdown Device Owner mode additionally requires a computer, USB cable, ADB, and the ability to remove every active account from the tablet.Guide 1 ↗
  • Rough steps For a basic test, install and open FreeKiosk, tap the bottom-right secret button five times, enter the PIN, set the URL/app, and start kiosk mode. For full lockdown, install but do not open the app, authorize USB debugging, confirm the device with adb devices, then run dpm set-device-owner; open and configure FreeKiosk only after the command reports Success.Guide 1 ↗
  • When to stop Stop if Android is below 8.0, adb shows unauthorized/no device, active accounts cannot be removed, or dpm does not report Success; do not assume Device Owner is active. Before uninstalling, use Remove Device Owner in the app or ADB remove-active-admin—Exit Kiosk Mode does not remove device ownership.Guide 1 ↗

Before you start

  • Do not flash, disassemble, or buy parts without installation and recovery material for the exact model, hardware revision, and firmware.
