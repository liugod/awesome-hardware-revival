开始前的三点

  • 你需要什么 EasyNAS 的已核前提：x86_64 有启动安装 ISO，ARM 有磁盘镜像；首启向导和 Web UI 管理磁盘、存储池、共享与插件。教程 1 ↗ · 教程 2 ↗
  • 大致步骤 按链接上游安装/配置路径执行 EasyNAS；本次有证据的目标仅为：提供 Btrfs 存储池、RAID、压缩、快照、自描述池与 Samba/NFS 等完整 NAS 功能。教程 1 ↗ · 教程 2 ↗
  • 何时停止 EasyNAS：若无法接受以下风险或没有对应回退路径就停止：安装器会写系统盘，数据盘流程包含擦除和准备；自描述池利于重装后发现，但不能替代备份和目标盘确认。教程 1 ↗ · 教程 2 ↗
