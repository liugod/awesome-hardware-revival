Decide before you build

  • Current stage The author plans to let a Pico rewrite EPUB/PDF files on an SD card so an old Sony PRS-700 can display changing text; the work remains at research and parts-gathering stage.
  • Practical readiness It is currently an idea for file injection on an older reader, not a buildable conversion.
  • User value Preserves a route that may avoid direct high-voltage panel driving while exposing the unresolved assumptions.
  • Follow-up recommendation Continue for protocol research; choose a demonstrated route for a dependable display.
