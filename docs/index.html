Before opening the case

Make three decisions first.

  1. Does the model match?Check generation, region, firmware, and board revision. A shared product name is not enough.
  2. What does the source prove?Separate install docs, author hardware evidence, and independent reproduction. A demo is not universal compatibility.
  3. When should you stop?Confirm a rollback path. Stop at an unknown board, irreversible step, or unclear power requirement.
