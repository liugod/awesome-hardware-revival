是否值得继续

  • 当前阶段 目标很明确：为 geekmagic ultra 使用 ESPHome 配置，摆脱或减少原厂云依赖，并接入 Home Assistant 等本地系统。
  • 现在能用到什么程度 可作为准确型号的配置入口；在核对芯片和硬件修订前，不能把它当成即刷即用固件。
  • 用户价值 把分散的 ESPHome 设备配置落到具体型号，方便先判断是否值得拆机和继续查证。
  • 继续跟进建议 如果型号和芯片完全一致，值得继续；任一硬件修订不明时先停在资料核对阶段。

适用设备与限制

已知可参考或可继续核查

  • 准确型号为 geekmagic ultra 的设备
  • 愿意核对芯片、PCB 和刷写方式的 ESPHome 用户

不能视为已支持

缺口、下一步与风险

  • 为什么仍是 E0 本轮确认了上游设备库中存在这个型号的配置页，但尚未逐项复核页面里的芯片、PCB 修订、刷写方式和全部功能。
  • 下一步核验 打开型号页核对主控芯片、引脚、硬件版本和刷写入口；再找同版 PCB 的成功记录与恢复路径。
  • 风险与停止条件 涉及市电的设备必须断电操作，不能在外壳打开时带电调试；型号名相同也可能换芯，先确认 PCB。
