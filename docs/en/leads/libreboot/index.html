Libreboot: open firmware hosted outside GitHub

Official documentation and the build system live on the project site and Codeberg, with board-specific install paths.

L02 · E0 · Sources reviewed 2026-10-21 · No hands-on hardware tests

DECIDE BEFORE YOU BUILD

Current stage

The upstream project and documentation are substantial, with explicit supported devices and install routes; KitAgain has not normalized every board.

Practical readiness

Exact boards in the current official list can enter installation assessment. Some support internal flashing; others require external hardware.

Device fit and limits

Known fit or worth checking

  • Official ThinkPad X200/T400/T500/W500/R400/R500 routes
  • Official X220/X220T/T420/T420s/T520 and X230/T430/T530/W530/X230T routes
  • Exact Chromebook, server, desktop and workstation boards in the current list

Not established or unsuitable

  • Board revisions absent from the current list despite a similar family name
  • Removed boards or devices with only old instructions and no current ROM
  • Machines whose flash chip, backup and external recovery path cannot be confirmed

Why this lead is useful

The support list can support a real board, flashing and recovery decision. Firmware-writing risk is the main issue.

Should you continue?

Continue if you can identify the board, back up the complete flash and prepare recovery hardware; stop if you cannot accept a non-booting machine.

Why it remains E0

The upstream material is substantial, but KitAgain has not yet converted supported boards, internal/external flashing, license scope and recovery equipment into a reviewed catalog entry.

Next review step

Start with one exact ThinkPad or Chromebook board and verify its ROM, flashing method, backup and rollback.

Risk and stop condition

This writes boot firmware. Upstream requires a flash backup and warns that incorrect steps can leave the machine unable to boot.
