CM311-1a-YST：把电视盒子改成 Armbian 小服务器

  • 目标是让 CM311-1a-YST 从安卓电视盒子变成 Armbian 小主机，可承载 Docker、文件服务、Home Assistant 或轻量网络服务。

具体型号核查

  • 硬件确认 魔百盒 CM311-1a-YST，S905L3A；支持表列为 stable 路线。
  • 改造路线 先外置启动并核对安卓分区布局，再使用适配该布局的 armbian-install 方案。
  • 可以做到什么 可作为 Armbian 小服务器，但 eMMC 安装必须处理这个运营商盒子的分区差异。
  • 不能扩大解释的边界 issue 517 记录默认安装会因安卓分区不同出现 BTRFS 报错，不能套用其他 CM311 变体步骤。
  • 恢复与停止条件 完整备份 eMMC 分区表和原厂包；安装脚本未明确适配 YST 版本时停在外置启动。
  • 上游版本 4a96bb2b63c4b3ce36051e439f48f309af4fef79

是否值得继续

  • 当前阶段 具体型号的上游配置或维护记录已读，证据升级为 E1；KitAgain 仍未实机验证。
  • 现在能用到什么程度 可作为 Armbian 小服务器，但 eMMC 安装必须处理这个运营商盒子的分区差异。 使用前仍要遵守本页的型号边界。
  • 用户价值 魔百盒 CM311-1a-YST，S905L3A；支持表列为 stable 路线。 先外置启动并核对安卓分区布局，再使用适配该布局的 armbian-install 方案。
  • 继续跟进建议 完整备份 eMMC 分区表和原厂包；安装脚本未明确适配 YST 版本时停在外置启动。

适用设备与限制

已知可参考或可继续核查

  • 准确型号为 CM311-1a-YST 且 SoC/主板一致的盒子
  • 愿意先用 USB/TF 做非破坏性启动验证的用户

不能视为已支持

  • 同名但主板、Wi-Fi 或存储芯片未知的盒子
  • 没有原厂固件备份就准备直接写 eMMC 的设备

缺口、下一步与风险

  • E1 还没有证明什么 已读取具体型号的配置或维护资料，但 KitAgain 没有实机刷写、测量或长期运行；上游记录也不能保证当前零售批次完全相同。
  • 下一步核验 把实物型号、PCB 和主控与资料逐项对照，再从低风险步骤开始验证。完整备份 eMMC 分区表和原厂包；安装脚本未明确适配 YST 版本时停在外置启动。
  • 风险与停止条件 先备份原厂安卓与启动分区；设备树不匹配时可能无显示、无网或无法启动，未验证前不要直接覆盖 eMMC。
