M5Stack Core2 (K010): flash Tasmota for local control

The goal is to configure Tasmota for M5Stack Core2 (K010) so its switch, light, plug or sensor can be controlled locally through the web UI, MQTT or a home-automation system.

D174 · E1 · Sources reviewed 2026-10-22 · No hands-on hardware tests

EXACT-MODEL SOURCE REVIEWED

Hardware

M5Stack Core2 K010 ESP32 touchscreen kit with sensors and SD card.

Installation route

Use the tasmota32-lvgl build and automatic-configuration template.

Expected result

Upstream describes full sensor and SD support for a local touch panel or status display.

Boundary

Only Core2/K010 is covered; Core, CoreS3 and clones use different targets.

Recovery and stop condition Preserve the factory image and verify USB flashing; restore by exact model if display or touch initialization fails.

Upstream revision 882b871653fd23fcf651161c7dafda6a638783c2
