Exact-model review

  • Hardware CM311-1a-YST carrier box with S905L3A, listed on the stable route.
  • Installation route Boot externally, inspect the Android partition layout and use an armbian-install path adapted to that layout.
  • Expected result Can become a small Armbian server, but eMMC installation must account for this carrier box's partitions.
  • Boundary Issue 517 reports BTRFS errors from the differing Android layout; instructions for other CM311 variants are not interchangeable.
  • Recovery and stop condition Back up the full eMMC partition table and stock image; remain on external boot until the install script explicitly supports the YST layout.
