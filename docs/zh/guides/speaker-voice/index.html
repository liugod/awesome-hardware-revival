旧音箱接 AI：桥接、刷机和换板是三条路

先决定是否接受厂商云依赖、拆机与外部主机，再选择适合自己音箱的路径。

保留原固件：服务桥接

  • XiaoGPT 把请求交给外部模型，README 给出 LX06 配置示例；仍依赖小米账号和语音接口。
  • 先完成一次问答并测试停止桥接后原功能是否正常；不能据此承诺所有小爱音箱都兼容。

接管音频：型号限定的补丁固件

  • Open-XiaoAI 区分 LX06 和 OH2P，拆机方式与连接线不同，不能互套镜像。
  • 仓库已归档。双分区回退依赖原分区完好，必须先准备备份与恢复资料。

复用外壳与扬声器：替换主板

  • Onju 使用第二代 Nest Mini 与替换 PCB，不是给原 Google 固件装一个应用。
  • 原版已停止积极维护，v2 是同一家族后继；早期演示不是所有 v2 功能的证明。
  • 若手里是通用 Linux 设备，可另看 Linux Voice Assistant，但音频驱动、架构和 Home Assistant 服务仍需核对。

共通的验收条件

  • 音频输入、播放、网络和模型后端分别验证，再测完整对话与重启。
  • 断网或后端失效时应能判断失败。保留原主板或可回退配置。
  • 常开主机、PCB、语音和模型服务可能产生成本，当前金额未知；本站没有实机或延迟测试。
