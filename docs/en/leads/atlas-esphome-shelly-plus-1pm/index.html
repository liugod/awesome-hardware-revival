Shelly Plus 1PM: convert it to a local ESPHome device

The goal is clear: use an ESPHome configuration for Shelly Plus 1PM, reduce dependence on the vendor cloud and connect it to a local system such as Home Assistant.

EXACT-MODEL SOURCE REVIEWED

Hardware

ESP32-U4WDH with a documented 2021 single-core PCB v0.1.9 and 2026 dual-core PCB v0.2.0.

Installation route

Select CPU settings by board revision, then configure the relay, BL0937 metering, NTC and add-on interface.

Provides local relay control, power and voltage measurement, temperature monitoring and add-on inputs.

Boundary
