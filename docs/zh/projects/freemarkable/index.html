freeMarkable：为 reMarkable 安装 XOVI 与第三方应用入口

用户结果

通过电脑端 Python GUI 和 reMarkable 的 SSH/USB 网络连接安装 XOVI、AppLoad，并可选集成 KOReader；这是修改设备软件栈的工具，不是普通文档同步应用。

E0 · 待验证了解证据与评分 ↗

项目概述

在上游列出的 reMarkable 设备上获得第三方应用框架与启动入口。

适用设备

  • 上游 README 列出 reMarkable 1（armv6l）、reMarkable 2（armv7l/armhf）和 reMarkable Paper Pro（aarch64/arm64）。
  • 支持范围是上游作者声明；KitAgain 没有在这些设备上独立安装或验证。
  • reMarkable 与 Kindle 不是同一平台；下方墨水屏专题仅作相邻决策入口，不能互换安装步骤。

适合谁

  • 拥有上游列出的 reMarkable 型号，并愿意维护 SSH、Python 与第三方应用框架。
  • 需要 XOVI/AppLoad 或 KOReader 入口，且能承担系统修改与恢复核对。

先别选，如果

  • 只想同步文档、不能启用 SSH，或不能保留并验证备份。
  • 需要厂商支持不变、零维护或已由 KitAgain 证明的兼容性。

动手前

  • 电脑需要 Python 3.10 或更高版本、互联网连接，以及可运行项目启动脚本的 Windows/Linux 环境；README 也声称跨平台支持。
  • 设备需要启用 SSH，并通过 USB 或 Wi-Fi 连接；上游明确建议只用 USB，Wi-Fi 不推荐。
  • 安装前确认设备电量充足、架构检测结果正确，并能读回自动生成的备份。

停止条件

  • 设备型号或 CPU 架构与上游表不一致，SSH 不可用，或电脑无法建立稳定 USB 网络连接时停止。
  • 安装器没有成功创建可读备份、无法说明恢复位置，或用户不能接受修改系统组件时停止。
  • 不要把上游“全设备支持”“可靠安装”等作者陈述当作 KitAgain 的兼容或成功保证。

风险与恢复

主要风险

  • 该路线安装 XOVI、AppLoad、可选 KOReader 和系统服务，会修改设备软件环境。
  • 上游声明自动备份、恢复和卸载能力，但本页没有独立验证这些恢复步骤。
  • 固件升级、架构变化、Xochitl/USB 连接异常和第三方组件更新都可能改变当前行为。

回退边界

  • 开始前保存安装器创建的备份、记录设备软件版本和连接方式，并确认备份可访问。
  • 安装后若主应用或 USB 连接异常，先按上游已记录的连接排障；若无法确认恢复路径，不继续叠加安装。
