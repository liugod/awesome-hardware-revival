先判断是否值得继续

当前阶段

作者为 Acer/eMachines MP-09B23U4-6983 键盘反查矩阵，并用回收的 STM32 制作 USB 键盘控制器。

现在能用到什么程度

对准确型号可成为 USB 键盘，方法也适合学习矩阵逆向。

适用设备与不能这样用的情况

已知可参考或可继续核查

  • Acer MP-09B23U4-6983 / PK130C93A00 作者型号
  • 可逐键测量矩阵和焊接 FPC 的开发者

不能视为已支持

  • 任意笔记本键盘直接插 USB
  • 带复杂背光、触控或专用控制芯片但无资料的模块

对用户有什么价值

保留手感好的旧键盘，并展示型号级逆向过程。

是否值得继续跟进

型号相同可深入；型号不同先把它当新的矩阵测绘项目。

为什么仍是 E0

笔记本键盘矩阵、FPC 和连接器高度不标准；目前是单一稀有型号的作者结果。

下一步核验

保存完整矩阵、固件、连接器规格和另一台主机的 USB 枚举测试。

风险与停止条件

错误电压可能损坏键盘或控制器；先用限流电源和万用表查矩阵。
