当前阶段

现在能用到什么程度

主板和屏幕仍工作时，可高度复用整机部件做固定媒体终端。

适用设备与不能这样用的情况

已知可参考或可继续核查

  • 屏幕、主板和扬声器尚可工作的旧笔记本
  • 能制作机箱和重新布置散热的制作者

不能视为已支持

  • 主板或屏幕已损坏的机器
  • 没有锂电安全经验却照搬电池步骤

对用户有什么价值

比只拆屏更充分地复用原机部件，并给出完整机械过程。

是否值得继续跟进

先做无电池插电版本；功能和温度稳定后再完善外壳。

为什么仍是 E0

作者涉及拆电池包并测试 18650；该部分不适合普通用户复制，软件版本也可能过时。

下一步核验

优先做插电版本，核对主板散热、屏线、扬声器功放、自动启动和遥控。

风险与停止条件

不要自行拆解和重组未知状态的笔记本电池包；裸主板与电源要可靠固定。
