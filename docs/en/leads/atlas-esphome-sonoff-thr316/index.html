Sonoff THR316: convert it to a local ESPHome device

The goal is clear: use an ESPHome configuration for Sonoff THR316, reduce dependence on the vendor cloud and connect it to a local system such as Home Assistant.

D077 · E1 · Sources reviewed 2026-10-22 · No hands-on hardware tests

EXACT-MODEL SOURCE REVIEWED

Hardware

ESP32 with one relay, three LEDs, button and RJ9 bus for an external DS18B20 sensor.

Installation route

Use the documented GPIO and RJ9 pinout to combine the temperature sensor and relay as a Home Assistant thermostat.

Expected result

Monitors temperature locally and switches a heating load around a set point.

Boundary

The example assumes DS18B20; other temperature/humidity probes and THR316D are not drop-in equivalents.

Recovery and stop condition Keep the relay off at boot and validate sensor readings plus short/long button behavior before connecting a real load.
