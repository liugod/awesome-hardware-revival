社区线索与未完成项目

这些线索来自 GitHub 之外的论坛、作者网站、Codeberg、GitLab、Hackaday、Instructables 等。所有条目当前均为 E0：有价值，但尚未达到正式目录的完整核验要求。

E0 的含义

可能是项目不完整、只有单一作者报告、型号范围不清，或只是 KitAgain 还没查完。页面会明确写出是哪一种。
