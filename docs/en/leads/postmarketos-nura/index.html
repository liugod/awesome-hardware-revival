postmarketOS / Nura: Linux routes for older phones

The project is not GitHub-centered. Its download entry currently redirects to Nura, while device material and code remain distributed across a wiki and GitLab.

L01 · E0 · Sources reviewed 2026-10-21 · No hands-on hardware tests

DECIDE BEFORE YOU BUILD

Current stage

The ecosystem is active while entry points move to Nura. Device material and code remain available, but model-by-model review is incomplete.

Practical readiness

Proceed only when a current device page names the exact codename, install route and feature state. This is not a universal flashing guide.

Device fit and limits

Known fit or worth checking

  • Exact codenames listed in the current device directory
  • Spare phones with a matching install page or build package and a documented stock recovery route

Not established or unsuitable

  • Similar retail names with a different codename
  • Phones absent from the directory or with unknown core-function status
  • Daily-driver use requiring reliable calls, camera, positioning and every stock function

Why this lead is useful

Helps determine whether an older phone has a Linux route and where functionality is missing. Its value is triage, not a success guarantee.

Should you continue?

Continue if you know the codename, accept feature-matrix review and can restore stock firmware; pause if you only know the retail name.

Why it remains E0

KitAgain has not yet reconciled the brand migration, current support levels, calling/camera matrices, or a tested route for any exact phone.

Next review step

Select three exact older models and review each device page, installation route, mainline-kernel status and recovery path.

Risk and stop condition

Match the exact device codename before flashing; similar retail names do not make images interchangeable.
