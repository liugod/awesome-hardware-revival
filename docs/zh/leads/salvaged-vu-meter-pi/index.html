先判断是否值得继续

当前阶段

教程分析回收的 VU 表头灵敏度，并比较 PWM 与 DAC 驱动，让指针显示树莓派负载或音频状态。

现在能用到什么程度

可把旧音响指针表变成低速状态仪表，教程对新手较友好。

适用设备与不能这样用的情况

已知可参考或可继续核查

  • 可独立取出的模拟 VU 表或低压表头
  • 树莓派 PWM/DAC 状态显示

不能视为已支持

  • 未知量程下直接接 3.3V/5V
  • 要求精密快速测量的仪器

对用户有什么价值

帮助用户先测参数再复用，而不是凭外观接线。

是否值得继续跟进

能测量灵敏度并限流时继续；稀有原机优先无损修复。

为什么仍是 E0

表头参数差异很大，项目没有给出每种旧机芯的通用限流值，也未验证长期机械磨损。

下一步核验

测量目标表头满量程电压/电流，做限流、校准和断电归零测试。

风险与停止条件

先把表头从原市电音响电路完全拆离，用低压限流电源测试。
