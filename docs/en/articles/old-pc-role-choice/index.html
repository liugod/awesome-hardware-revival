Home server, media center or NAS: choose a role for an old PC

Choose one job first, then check boot mode, disks and networking. HAOS, DietPi, openmediavault and LibreELEC are not interchangeable “old PC operating systems.”

C02 · Sources reviewed 2026-10-21 · No hands-on hardware tests

Define the job before choosing the route

For a dedicated smart-home controller, examine the Home Assistant OS Generic x86-64 route. For flexible lightweight Linux services, consider DietPi. For local disks and shared folders, compare openmediavault. For a PC connected to a TV as a Kodi endpoint, look at LibreELEC.

“Home server” is not a testable goal. List the devices or services to connect, data volume, always-on needs, whether a local screen matters, and what should continue working when the network fails. These decisions change disk and backup requirements.

Boot and installation boundaries

The official HAOS Generic x86-64 route requires UEFI boot, Secure Boot disabled, and a boot medium with 512-byte logical sectors (512n/512e). A 64-bit CPU alone is insufficient. Confirm the exact target disk before writing an image.

DietPi lists separate Native PC paths for UEFI and BIOS/CSM, and distinguishes installers from direct-write images. Identify your boot mode first. LibreELEC's Generic download page separates the regular image from legacy/NVIDIA-oriented options; x86-64 by itself is not enough to select one blindly.

Storage and data risk

The official openmediavault ISO instructions tell you to disconnect every disk except the intended OS drive before installation and warn that existing data on the installation target will be lost. Reconnect data drives after installing; never use a disk containing your only copy as a trial target.

For any route, check disk health, an independent backup, recovery after power loss, and the distinction between OS and data disks. RAID or two disks are not a backup. Power draw, noise, disk life and actual cost must be measured on the specific PC; this catalog has no such measurements.

Minimum acceptance and reasons to pause

On the actual hardware, test boot, networking, reboot and one real job: pair a device with HAOS, run a defined service on DietPi, read an openmediavault share from another device, or play local media you may legally use with LibreELEC. Then test backup and restore.

If boot mode, target disk or backup state is unknown, pause before installation. The linked project pages retain primary sources and specific limits. This comparison is not a catalog-run hardware installation report and does not certify every old PC.
