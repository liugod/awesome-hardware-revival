是否值得继续

  • 当前阶段 作者修改 DEC LA30 打印终端的字符发生器板，让计数器轮询字库并用七只 LED 显示点阵行数据。

  • 用户价值 保留了一种从废板理解早期字符生成逻辑的做法。
  • 继续跟进建议 拥有同板且以学习为目标时跟进；普通废打印机先回收电机、导轨和电源。

适用设备与限制

已知可参考或可继续核查

  • 相同 DEC LA30 字符板或同类可识别字库板
  • 想观察旧 ROM 字符数据的学习实验

不能视为已支持

  • 通用打印机主板复用方法
  • 需要实际打印或显示文字的成品

缺口、下一步与风险

  • 为什么仍是 E0 这是针对特定古董板卡的单例创作，没有通用接口或现代替代料路线。
  • 下一步核验 保存板号、ROM 型号、改线图和工作视频，确认是否有可重复接线说明。
  • 风险与停止条件 只使用拆下并确认低压的逻辑板，不要给未知老设备整机上电。
