Decide before you build

  • Current stage The ecosystem is active while entry points move to Nura. Device material and code remain available, but model-by-model review is incomplete.
  • Practical readiness Proceed only when a current device page names the exact codename, install route and feature state. This is not a universal flashing guide.
  • User value Helps determine whether an older phone has a Linux route and where functionality is missing. Its value is triage, not a success guarantee.
  • Follow-up recommendation Continue if you know the codename, accept feature-matrix review and can restore stock firmware; pause if you only know the retail name.

Device fit and limits

Known fit or worth checking

  • Exact codenames listed in the current device directory
  • Spare phones with a matching install page or build package and a documented stock recovery route

Not established or unsuitable

  • Similar retail names with a different codename
  • Phones absent from the directory or with unknown core-function status
  • Daily-driver use requiring reliable calls, camera, positioning and every stock function

Gaps, next step, and risk

  • Why it remains E0 KitAgain has not yet reconciled the brand migration, current support levels, calling/camera matrices, or a tested route for any exact phone.
  • Next review step Select three exact older models and review each device page, installation route, mainline-kernel status and recovery path.
  • Risk and stop condition Match the exact device codename before flashing; similar retail names do not make images interchangeable.
