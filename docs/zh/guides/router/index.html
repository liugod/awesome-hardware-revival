旧路由器再利用：刷机前先核对型号、分区与恢复

OpenWrt 或 FreshTomato 能否使用取决于准确型号和硬件修订；固件文件名、论坛包或相似外观都不能替代逐型号安装资料。

先找到准确配置档

  • 记录底部标签、地区版本与硬件修订，再到上游支持表或固件选择器定位准确配置档。
  • Xiaomi AX9000、AX3000T、4A Gigabit 与 Redmi AX6S 是不同目标；不能因品牌相同而互换镜像。

区分升级与首次安装

  • sysupgrade、factory、initramfs 等文件承担不同用途；只按准确设备页的首次安装说明操作。
  • 社区汇总适合发现型号，但不能替代官方设备 Info、分区布局、引导方式与恢复步骤。
  • FreshTomato 只适用于其支持表内设备；没有列出型号时不要据此推断可用。

先准备恢复，再判断用途

  • 保存原厂配置与必要分区，确认救援模式、串口或厂商恢复工具确实适用于该修订。
  • 先验证有线网络、管理入口、重启和回滚，再考虑拨号、无线或附加服务。
  • 本站没有对吞吐、覆盖、功耗或长期稳定性做实机比较。
