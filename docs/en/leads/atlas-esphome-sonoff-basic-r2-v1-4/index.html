Sonoff BASIC R2 v1.4: convert it to a local ESPHome device

The goal is clear: use an ESPHome configuration for Sonoff BASIC R2 v1.4, reduce dependence on the vendor cloud and connect it to a local system such as Home Assistant.

D073 · E1 · Sources reviewed 2026-10-22 · No hands-on hardware tests

EXACT-MODEL SOURCE REVIEWED

Hardware

ESP8285 with GPIO0 button, GPIO12 relay/red LED and GPIO13 blue status LED.

Installation route

Apply the v1.4 ESPHome configuration and compare the unit against the older and 2023 PCB photos.

Expected result

Provides local single-relay control with consistent button and dual-color indicator behavior.

Boundary

v1.4 LED behavior differs from earlier versions and the red LED cannot be controlled independently without modification.

Recovery and stop condition Match the PCB photos to v1.4 first; stop rather than reuse the GPIO map on another revision.
