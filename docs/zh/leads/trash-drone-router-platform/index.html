先判断是否值得继续

当前阶段

作者把旧路由器、PIC、Wii 传感器、IP 摄像头和电机组合成低成本联网无人机平台，并公开论文、博客与飞控代码入口。

现在能用到什么程度

可研究废旧路由器作为机载联网节点的系统思路，不适合作为当前即用无人机套件。

适用设备与不能这样用的情况

已知可参考或可继续核查

  • 旧 OpenWrt 类路由器与可替换传感器的实验
  • 研究低成本空中网络的平台设计

不能视为已支持

  • 直接复制为可安全飞行的成品
  • 未经法规和失效测试的户外飞行

对用户有什么价值

把多类废件如何组成完整系统记录在一起，可用于架构与失败模式研究。

是否值得继续跟进

做历史技术研究可继续；实际飞行应从当前受支持的飞控与安全链开始。

为什么仍是 E0

资料跨多个旧链接，项目已多年未更新；飞行安全、无线法规、当前代码和具体硬件版本未统一核对。

下一步核验

保存仍可访问的代码和论文，确认一套实际机体、控制链与失控保护。

风险与停止条件

旋翼、电池和无线发射都有现实风险；没有失控保护和合法频段时不应飞行。
