开始前的三点

  • 你需要什么 Android 设备、要固定展示的 Home URL，以及可用的设备凭据或生物识别，用于进入受保护的设置。只在网页确有需要时准备相机、麦克风、位置或 NFC 权限。教程 1 ↗ · 教程 2 ↗ · 教程 3 ↗
  • 大致步骤 按安装页选择可核验的安装渠道；在 Web Content 设定 Home URL，测试页面、必要权限与设置解锁；从 Setting Actions 导出 JSON/Base64 配置备份；最后才启用屏幕固定/Lock Task，需要时再设为默认 Launcher。教程 1 ↗ · 教程 2 ↗ · 教程 3 ↗
  • 何时停止 在设置解锁方式、Kiosk Control Panel 或导出配置备份未实测前，不要设默认 Launcher 或持久锁定。启用 Device Owner 时，若无法清除额外用户/账号或 dpm set-device-owner 失败，就停止并保留普通屏幕固定模式。教程 1 ↗ · 教程 2 ↗
