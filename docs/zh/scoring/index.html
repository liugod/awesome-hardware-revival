1–5 星复活价值评分

只计有证据维度、权重重新归一、证据等级独立。

星级回答什么

它用于比较一条复活路线的落地条件，不是兼容保证、安全认证或成功率。E0–E3 单独表示来源证据深度，不参与星级加权，也不设置上限。

五个维度与权重

维度权重
可行性 / 上手难度（越容易分越高）25%
成本（越低分越高）15%
文档与社区活跃度20%
实用价值20%
刷坏与安全风险（风险越低分越高）20%

计算方式

每个有可核验来源的维度给 1–5 分。仅将已取证维度的原权重按比例重新归一到 100%，再求加权平均；四舍五入到最近的 0.5 星，正好落在中点时向上取整。

未知项怎样处理

缺少证据的维度保留为 null，不再用 3 分占位，也不进入分母。少于 3 个维度有证据时，总分和加权平均均为 null，页面显示“待评分”，并排在所有已评分条目之后。
