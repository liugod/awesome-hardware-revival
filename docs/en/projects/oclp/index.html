OpenCore Legacy Patcher

What this project does

Provide boot and driver patches for selected Macs no longer officially supported by newer macOS versions.

What changes for this device

Before

Some Intel Macs still work but are outside official support for certain macOS releases.

After

OpenCore boot support and model-specific patches can allow otherwise unsupported macOS versions to run.

Compatibility is more than the year of manufacture. The official list distinguishes model identifiers and graphics, wireless and other patch conditions; it excludes Apple Silicon and PowerPC. OS updates may require patch reapplication. Booting does not prove that every peripheral or graphics acceleration works. Prepare a recoverable backup and separate boot media before deciding whether this is suitable for daily use.

A good fit for

People able to identify their Intel Mac model, back up data and handle OS updates themselves.

Not a good fit for

People with only one essential work computer, requiring uninterrupted use, or treating Apple Silicon as the same route.

Proposed reproduction checks

  • Check the model identifier, target macOS and patch requirements.
  • Check graphics acceleration, Wi-Fi, sleep, external displays and everyday software individually.
  • Verify the backup is readable and retain a route to recover the original OS.

These hardware checks have not been performed by this catalog.
