是否值得继续

  • 当前阶段 教程形成完整作者构建路线，可复用 Play:1 箱体和扬声器；KitAgain 尚未复现或核对全部修订。
  • 现在能用到什么程度 故障或闲置 Play:1 可移除原主板并改成树莓派有源音箱；需要拆机、焊接、匹配功放和市电安全经验。
  • 用户价值 完成度较高，能直接判断所需 Pi、功放、供电和软件步骤；核心价值是机械与电气路线。
  • 继续跟进建议 有焊接和市电安全经验且扬声器单元正常时继续；只想软件解锁或无法安全放电时不要尝试。

适用设备与限制

已知可参考或可继续核查

  • 扬声器单元正常的 Sonos Play:1 箱体与 4Ω 单元
  • 教程使用的 Raspberry Pi 3 Model A+，以及明确提到的 Raspberry Pi Zero 2
  • 能驱动 4Ω 单元的 DAC/功放组合和独立 20V 供电

不能视为已支持

  • 假设其他 Sonos 型号内部空间、阻抗和接线相同
  • 保留原主板功能、Sonos 多房间协议或认证
  • 没有市电设备安全经验的人处理原主板电容

缺口、下一步与风险

  • 为什么仍是 E0 KitAgain 尚未核对不同 Sonos 修订、供电/功放匹配、完整成本和教程内容许可，也没有实机复现。
  • 下一步核验 以 Play:1 的具体硬件修订整理拆机、扬声器阻抗、独立电源、音频软件和验收项。
  • 风险与停止条件 原机使用市电，主板电容可能残留危险电压；这不是无经验用户的低风险拆机项目。
