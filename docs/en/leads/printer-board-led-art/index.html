Decide before you build

  • Current stage The author modifies a DEC LA30 terminal character-generator board so counters scan its ROM and seven LEDs expose dot-matrix row data.
  • Practical readiness A digital-logic and font-ROM teaching artifact with limited practical function.
  • User value Preserves a way to learn early character-generation logic from a discarded board.
  • Follow-up recommendation Follow if you own the same board and want to learn; for ordinary printers salvage motors, rails and supplies first.

Device fit and limits

Known fit or worth checking

  • The same DEC LA30 character board or a similar identifiable ROM board
  • Learning experiments that expose old font data

Not established or unsuitable

  • A universal printer-mainboard reuse method
  • A finished device that prints or displays full text

Gaps, next step, and risk

  • Why it remains E0 This is a one-off work for a particular vintage board, without a universal interface or modern replacement-parts route.
  • Next review step Preserve board number, ROM type, wiring modifications and working video, and check for repeatable instructions.
  • Risk and stop condition Use only a removed logic board confirmed to be low voltage; do not power an unknown complete vintage machine.
