HA Lovelace Kindle Screensaver

What this project does

Render Home Assistant pages on a server and use an old Kindle only for display.

Specific modification route · Family kindle-ha · Reviewed 2026-10-20

Source repository ↗Original tutorial ↗Compatibility source ↗
Check the boundaries first

Jailbroken Kindles capable of running the screenshot display scripts.

  • Needs Home Assistant and a screenshot service. The screen is not running a complete browser application.

Firmware: Unknown · Region requirement: Unknown

What changes for this device

Before

An idle Kindle suits low-frequency information but cannot display every website like a modern tablet.

After

A server generates images of a Home Assistant dashboard, which the Kindle retrieves and displays.

The author uses a Kindle 4 as the example. Rendering happens on an external service; the device mainly displays the result. Troubleshoot Home Assistant page permissions, screenshot generation and device retrieval separately. Faster refresh is not necessarily more useful: measure e-ink delay, ghosting and battery consumption on your own hardware. This suits status boards, not video or high-frequency interaction.

A good fit for

Existing Home Assistant users wanting a small amount of persistent information on a wall or desk.

Not a good fit for

People requiring live animation, complex touch controls or no server at all.

Proposed reproduction checks

  • Generate a correctly sized screenshot first, then verify device display.
  • Test expired authentication and network outages to avoid silently displaying stale information.
  • Measure refresh intervals and actual power use; show the data update time.

These hardware checks have not been performed by this catalog.
