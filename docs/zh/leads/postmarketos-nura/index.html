是否值得继续

  • 当前阶段 生态仍在运行，入口正迁移到 Nura；设备资料和代码可找到，但尚未逐机型核验。
  • 现在能用到什么程度 只有当前设备页明确列出准确代号、安装路径和功能状态时，才适合进入试装准备；不是通用刷机教程。
  • 用户价值 用来判断旧手机是否存在 Linux 路线，以及功能缺口在哪里；价值是设备筛选，不是成功保证。
  • 继续跟进建议 知道设备代号、愿意读功能矩阵并能恢复原厂系统时继续；只知道品牌型号时先停。

适用设备与限制

已知可参考或可继续核查

  • 当前设备目录明确列出的准确设备代号
  • 有对应安装页或构建包，并具备原厂恢复资料的闲置手机

不能视为已支持

  • 零售名称相近但设备代号不同的机型
  • 设备页未列出或核心功能状态未知的手机
  • 依赖稳定通话、相机、定位等全部日常功能的主力机

缺口、下一步与风险

  • 为什么仍是 E0 KitAgain 尚未梳理品牌迁移、当前支持等级、通话/相机等功能矩阵，也没有针对具体手机完成实机验证。
  • 下一步核验 选 3 个具体旧机型，逐一核对设备页、安装方法、主线内核状态和恢复路径。
  • 风险与停止条件 刷写前必须按准确代号核对；同品牌相近型号不能互换镜像。

链接里分别有什么

  • 官方下载安装入口 ↗official-entry
    当前跳转到 Nura，用于确认迁移后的现行入口；不代表任意手机都有镜像。https://postmarketos.org/download/

    包含设备包、内核和构建定义；仓库存在不等于某台手机功能完整。https://gitlab.postmarketos.org/postmarketOS/pmaports
