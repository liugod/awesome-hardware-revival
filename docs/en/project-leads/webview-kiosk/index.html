Three checks before starting

  • What you need An Android device, the Home URL to display, and working device credentials or biometrics for protected settings. Plan camera, microphone, location, or NFC permissions only when the target web app actually needs them.Guide 1 ↗ · Guide 2 ↗ · Guide 3 ↗
  • Rough steps Choose a verifiable install channel from the installation page; set the Home URL under Web Content; test the page, required permissions, and settings unlock; export a JSON/Base64 settings backup from Setting Actions; only then enable screen pinning/Lock Task and, if needed, select the app as the default launcher.Guide 1 ↗ · Guide 2 ↗ · Guide 3 ↗
  • When to stop Do not make the app the default launcher or enable persistent lockdown until settings authentication, the Kiosk Control Panel, and an exported configuration backup have been tested. For Device Owner setup, stop if extra users/accounts cannot be cleared or dpm set-device-owner fails; keep the device in ordinary screen-pinning mode instead.Guide 1 ↗ · Guide 2 ↗
