Is my TV rootable with RootMyTV?

RootMyTV does not publish a blanket sales-model compatibility promise. Check the TV model year and the webOS TV Version shown in settings, not the model-specific Software Version. Upstream identifies these versions and later as patched: 2016 / 3.4.2, 2017 / 3.9.2, 2018 / 4.4.2, 2019 / 4.9.7, 2020 / 5.4.0, and 2021 / 6.3.0. Older versions may still fail; versions below 3.4.0 and TVs shipped with webOS 1, 2, 7 (22), or 8 (23) were never supported.

Risks before you try

  • Firmware downgrade is generally unavailable without existing root; stop if the version meets or exceeds the patched threshold.
  • Rooting is unsupported by LG; upstream gives no guarantee against damage and warns that it may affect the warranty.
  • An official update can remove root and prevent re-rooting, while staying on old firmware may limit LG Content Store installs, updates, or launches.
