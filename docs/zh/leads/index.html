社区线索与未完成项目

这些线索来自 GitHub 之外的论坛、作者网站、Codeberg、GitLab、Hackaday、Instructables 等。所有条目当前均为 E0：有价值，但尚未达到正式目录的完整核验要求。

E0 的含义

可能是项目不完整、只有单一作者报告、型号范围不清，或只是 KitAgain 还没查完。页面会明确写出是哪一种。

手机与平板Official site + GitLabE0

postmarketOS / Nura：旧手机 Linux 路线 ↗

项目资料不以 GitHub 为中心；下载入口目前跳转到 Nura，设备资料和代码仍分布在 Wiki 与 GitLab。

当前可用程度只有当前设备页明确列出准确代号、安装路径和功能状态时，才适合进入试装准备；不是通用刷机教程。

待核缺口 KitAgain 尚未梳理品牌迁移、当前支持等级、通话/相机等功能矩阵，也没有针对具体手机完成实机验证。

手机与平板Home Assistant CommunityE0

旧平板作为 Home Assistant 墙面板 ↗

多个社区帖子记录用旧 Android 平板、Kiosk 浏览器或二手触屏设备展示 Home Assistant 仪表板。

当前可用程度较新的旧平板或手机通常可作 Home Assistant 仪表板终端，适合显示和轻量控制，不等于适合隐藏式长期供电。

待核缺口 这是一类分散经验，不是单一软件包；浏览器内核、Android 版本、充电策略、挂墙散热和长期电池安全差异很大。
