CM311-1a-YST: turn the TV box into an Armbian server

The goal is to convert CM311-1a-YST from an Android TV box into a small Armbian host for Docker, file services, Home Assistant or light network services.

D269 · E1 · Sources reviewed 2026-10-22 · No hands-on hardware tests

EXACT-MODEL SOURCE REVIEWED

Hardware

CM311-1a-YST carrier box with S905L3A, listed on the stable route.

Installation route

Boot externally, inspect the Android partition layout and use an armbian-install path adapted to that layout.

Expected result

Can become a small Armbian server, but eMMC installation must account for this carrier box's partitions.

Boundary

Issue 517 reports BTRFS errors from the differing Android layout; instructions for other CM311 variants are not interchangeable.

Recovery and stop condition Back up the full eMMC partition table and stock image; remain on external boot until the install script explicitly supports the YST layout.
