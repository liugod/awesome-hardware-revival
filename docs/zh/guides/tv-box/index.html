旧电视与电视盒再利用：媒体系统、网页应用还是 Linux？

先分清设备是智能电视还是电视盒，再核对芯片、固件与恢复路径；同名外壳和相近型号不能证明镜像兼容。

先确认设备类型

  • 电视盒路线通常依赖 SoC、主板、内存、网卡与设备树；商品名相同也可能更换内部硬件。
  • webOS 电视路线依赖具体固件和已公开入口；旧漏洞已修复时，不要把历史教程当作当前可用方案。

媒体系统还是小服务器

  • LibreELEC 与 CoreELEC 都是专用媒体系统；先在各自支持范围内找准确设备与当前镜像。
  • Armbian 盒子路线应先从 USB 或存储卡启动，确认网络和存储，再考虑写入 eMMC。
  • HK1 Box 仅在上游设备表与板型、设备树都匹配时继续；收录不等于 KitAgain 实机验证。

开始前的最低检查

  • 保存原厂固件、分区或原主板，并找到与准确硬件版本对应的恢复资料。
  • 分别验证启动、显示、网络、遥控、存储和重启；一项失败不能由其他项目的成功记录替代。
  • 本站没有补充功耗、性能、DRM 或长期稳定性测试；未知项继续保持未知。
