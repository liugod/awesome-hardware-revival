适用设备与限制

已知可参考或可继续核查

  • 面板本身正常且能找到精确匹配控制板的 LCD
  • 愿意制作安全外壳和固定支架的用户

不能视为已支持

  • 破裂 LCD 或无法读取面板编号
  • 把 30/40 针和 LVDS/eDP 当作可互换

缺口、下一步与风险

  • 为什么仍是 E0 旧教程依赖第三方卖家匹配；LVDS/eDP、背光、电源和固件必须按准确面板核对。
  • 下一步核验 读取面板背标完整编号，让控制板供应商书面确认分辨率、接口和背光，再台架测试。
  • 风险与停止条件 不要只按尺寸购买或带电插拔排线；CCFL 版本含高压逆变器。
