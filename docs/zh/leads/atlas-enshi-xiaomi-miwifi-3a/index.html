当前阶段

目标是把 Xiaomi MiWiFi 3A 改成可继续维护的 OpenWrt 路由器，用于拨号、旁路由、无线接入或基础网络服务。

现在能用到什么程度

可作为中文型号发现入口；尚不足以单独指导刷机。

适用设备与不能这样用的情况

已知可参考或可继续核查

  • 准确型号为 Xiaomi MiWiFi 3A 的路由器
  • 能进一步核对官方设备页和分区布局的用户

不能视为已支持

  • 仅凭外观判断型号的路由器
  • 无法备份或没有串口/救援恢复方案的高风险设备

对用户有什么价值

中文社区一次列出大量具体型号，适合快速判断手里设备是否值得进入下一轮核查。

是否值得继续跟进

官方设备页与硬件修订能对上时继续；只有第三方固件包而没有来源和恢复说明时不要刷。

为什么仍是 E0

中文论坛汇总页列出了这个型号，但它不是逐型号安装教程；硬件版本、引导布局、分区和恢复方法仍需回到官方设备页核对。

下一步核验

先查 OpenWrt 官方 Table of Hardware、固件选择器和该型号的硬件修订，再核对论坛帖中的固件来源与恢复方式。

风险与停止条件

不要混刷 U-Boot 布局与原厂布局镜像；升级前备份分区和校准数据，找不到精确硬件版本时停止。
