Community leads and incomplete projects

These leads come from forums, author sites, Codeberg, GitLab, Hackaday, Instructables and other sources beyond GitHub. Every entry is currently E0: useful, but not yet fully reviewed for the main catalog.

What E0 means

The project may be incomplete, supported only by one author report, unclear by model, or simply not fully reviewed by KitAgain. Each page states which case applies.

Phones & tabletsOfficial site + GitLabE0

postmarketOS / Nura: Linux routes for older phones ↗

The project is not GitHub-centered. Its download entry currently redirects to Nura, while device material and code remain distributed across a wiki and GitLab.

Review gap KitAgain has not yet reconciled the brand migration, current support levels, calling/camera matrices, or a tested route for any exact phone.

Computers & thin clientsOfficial site + CodebergE0

Libreboot: open firmware hosted outside GitHub ↗

Official documentation and the build system live on the project site and Codeberg, with board-specific install paths.

Review gap The upstream material is substantial, but KitAgain has not yet converted supported boards, internal/external flashing, license scope and recovery equipment into a reviewed catalog entry.

Routers & NASDoozan forumE0

Debian and U-Boot for older Kirkwood NAS devices ↗

Long-running material lives mainly in Doozan forum threads and replies, covering selected Zyxel, Seagate, Synology and Pogoplug devices.

Review gap There is no universal image for every NAS. Model, SoC, stock U-Boot, serial access, NAND layout and current downloads require thread-by-thread review.

Lead / not yet in reviewed catalogL03
Watches & wearablesOfficial help site + communityE0

Rebble: community services after Pebble shutdown ↗

An official HOWTO, help center, Discord and project pages collectively support setup, an app store and selected cloud services for older Pebble watches.

Review gap New Pebble app and service paths now coexist. KitAgain has not reconciled legacy Android/iOS versions, watch families, paid services and firmware combinations.

Phones & tabletsInstructablesE0

Jelloid: use an older Android device as a Jellyfin server ↗

The author published a step-by-step Instructable and reports tests on several Motorola devices, a Pixel and a Fire tablet.

Review gap KitAgain has not reproduced it or confirmed script maintenance, licensing, Android range, transcoding capability or background-process limits.

Lead / not yet in reviewed catalogL05
E-readers & e-inkHackaday.ioE0

Adapter board for salvaged Kindle displays ↗

A Hackaday project documents high-voltage drive rails, an adapter PCB and ESP experiments for 39-pin e-paper panels, including a successful black-and-white output log.

Review gap The project has been quiet for years, connectors and waveforms vary by panel, and the author recorded a screen damaged during an earlier board attempt.

Lead / not yet in reviewed catalogL06
E-readers & e-inkHackaday.ioE0

Six-inch Kindle display for Raspberry Pi: incomplete prototype ↗

The goal was a Raspberry Pi interface for a surplus Kindle panel. The author records that two PCB revisions contained errors and were unusable, then switched to another project.

Review gap There is no reproducible successful board, final BOM or acceptance result. Its value is preserving failure evidence and project relationships.

Phones & tabletsHome Assistant CommunityE0

Older tablets as Home Assistant wall panels ↗

Community threads document older Android tablets, kiosk browsers and second-hand touch devices used for Home Assistant dashboards.

Review gap This is a distributed pattern rather than one package. Browser engines, Android versions, charging control, wall cooling and long-term battery safety vary widely.

Speakers & voiceRaspberry Pi official magazine/tutorialE0

Upcycle a failed Sonos Play:1 with Raspberry Pi ↗

An official Raspberry Pi tutorial removes the original mainboard, keeps the enclosure and drivers, and adds a Pi, DAC and amplifier with follow-up software routes.

Review gap KitAgain has not checked Sonos hardware revisions, power/amplifier matching, full cost or tutorial licensing, and has not reproduced the build.

ESP32 Bluetooth receiver for an older stereo ↗

The author uses an ESP32, VS1053 and external antenna to stream phone audio to an older stereo, linking two code variants and a demonstration.

Review gap KitAgain has not checked code licensing, audio quality, latency, supply noise, amplifier inputs or long-term maintenance.
