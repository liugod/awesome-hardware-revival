Scraptop：把废笔记本变成手机扩展坞

项目尝试保留旧笔记本屏幕、键盘和外壳，通过 USB OTG、DisplayLink、DVI/LVDS 转换让手机成为计算核心。

L23 · E0 · 资料核查 2026-10-21 · 未进行实机测试

先判断是否值得继续

当前阶段

项目尝试保留旧笔记本屏幕、键盘和外壳，通过 USB OTG、DisplayLink、DVI/LVDS 转换让手机成为计算核心。

现在能用到什么程度

有价值的是整合路线和难点清单，当前不能当作通用转换板。

适用设备与不能这样用的情况

已知可参考或可继续核查

  • 外壳、键盘和 LCD 完整但主板报废的特定笔记本
  • 愿意处理多级视频转换和 USB 控制的开发者

不能视为已支持

  • 希望单根线连接任意手机和任意笔记本
  • 电池、LCD 或排线状态未知的机器

对用户有什么价值

把旧笔记本最难复用的键盘和屏幕接口问题集中呈现。

是否值得继续跟进

做接口研究可继续；实用扩展坞应先确认一个完整型号组合。

为什么仍是 E0

关键 DisplayLink/LVDS 链复杂且缺少完成验收；平板排线和控制器并不标准化。

下一步核验

确认是否完成可用组合、具体屏幕型号、键盘矩阵控制器和视频链延迟。

风险与停止条件

旧电池应移除或单独检测；CCFL 屏幕逆变器可能有高压。
