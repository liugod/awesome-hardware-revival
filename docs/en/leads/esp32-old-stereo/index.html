ESP32 Bluetooth receiver for an older stereo

The author uses an ESP32, VS1053 and external antenna to stream phone audio to an older stereo, linking two code variants and a demonstration.

L10 · E0 · Sources reviewed 2026-10-21 · No hands-on hardware tests

DECIDE BEFORE YOU BUILD

Current stage

The author marks it completed and provides two code variants, hardware components and a demo; KitAgain has not measured quality, latency, noise or stability.

Practical readiness

It can route phone A2DP audio through ESP32+VS1053 into an older stereo's line input, best as a reversible external receiver box.

Device fit and limits

Known fit or worth checking

  • ESP32-WROOM-32U with external antenna and generic VS1053 MP3 board
  • A regular ESP32 with the author's Adafruit VS1053 breakout route
  • Older stereos with AUX, Line In or another line-level input

Not established or unsuitable

  • Passive speakers with only speaker terminals
  • An ESP32 directly driving high-power speakers
  • Low-latency video sync, audiophile quality or every Bluetooth codec

Why this lead is useful

Adds phone Bluetooth input to an old amplifier through a reversible external box with clear parts and source routes.

Should you continue?

Continue if the stereo has line input and you can assemble low-voltage modules; choose a finished receiver for high fidelity, very low latency or mains-enclosure work.

Why it remains E0

KitAgain has not checked code licensing, audio quality, latency, supply noise, amplifier inputs or long-term maintenance.

Next review step

Verify pinouts, BOM and licenses for both board variants, then run a reversible test through a stereo line input.

Risk and stop condition

Prefer an external low-voltage line input. Any internal mains wiring requires separate isolation and electrical-safety review.
