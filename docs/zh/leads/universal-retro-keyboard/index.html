是否值得继续

  • 当前阶段 作者在 VCF 论坛公开可组合键盘矩阵和接口板，目标替代难找的 Apple II、OSI 等复古电脑键盘，并展示工作样机。
  • 现在能用到什么程度 对已覆盖机器可获得外观和手感更接近原机的新键盘。
  • 用户价值 解决原装键盘缺失这一常见复活瓶颈，并保留社区讨论过程。
  • 继续跟进建议 准确机型有对应接口时继续；稀有原键盘先修复保存。

适用设备与限制

已知可参考或可继续核查

  • 帖子和项目文件明确覆盖的 Apple II、OSI 等机器
  • 复古电脑修复和复制机

不能视为已支持

  • 任意老电脑的万能键盘
  • 不核对接口电平就接主板

缺口、下一步与风险

  • 为什么仍是 E0 不同机器的机械安装、键帽、接口电平和版本文件需要逐机核对；本轮直接访问论坛返回 503，正文依据搜索引擎已缓存的原帖内容。
  • 下一步核验 论坛恢复后从 Apple II 或 OSI 一种机器开始，确认 PCB 修订、接口板、键帽和固件。
  • 风险与停止条件 连接老电脑前核对电平和接口方向，避免损坏难以替换的主板。
