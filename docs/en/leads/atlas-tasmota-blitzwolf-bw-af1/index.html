EXACT-MODEL SOURCE REVIEWED

Hardware

BlitzWolf BW-AF1 air fryer with TYWE3S Wi-Fi module and TuyaMCU controller.

Installation route

Pry off the top cover for TYWE3S access, flash Tasmota over serial, then map temperature, time, mode and start/pause datapoints.

Expected result

Exposes status and cooking controls through MQTT/Home Assistant.

Boundary

This is a heating appliance; remote control never replaces supervision and datapoint mapping applies only to the documented firmware.

Recovery and stop condition Preserve original datapoints and test without food first; restore stock operation on any temperature, fan or safety-interlock anomaly.
