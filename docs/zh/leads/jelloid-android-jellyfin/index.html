适用设备与限制

已知可参考或可继续核查

  • 作者报告测试过的多台 Motorola、Pixel 和 Fire Tablet，但尚无准确型号矩阵
  • 主要承担直接播放、可长期接电并连接局域网的闲置 Android 设备

不能视为已支持

  • 需要可靠硬件转码、多用户高并发或公网暴露的服务器
  • Android 版本、CPU 架构和后台限制未核对的具体机型
  • 存放唯一媒体副本或要求无人值守稳定运行

缺口、下一步与风险

  • 为什么仍是 E0 KitAgain 尚未独立复现，也未确认脚本的长期维护、许可证、Android 版本范围、转码能力和后台保活限制。

  • 风险与停止条件 服务器会接触媒体文件和局域网；测试前使用副本，并检查应用来源、端口与权限。
