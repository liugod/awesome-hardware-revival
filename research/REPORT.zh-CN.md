# 老硬件复活项目研究 · v1.19.0

正式目录核查日期：2026-10-20；项目来源发现层更新：2026-10-24（条目保留 UTC 原始时间；本报告按 Asia/Shanghai 阅读）。

## 结论与适用范围

正式目录收录 53 条公开项目、平台和前置工具，覆盖 13 类设备，归并为 51 个项目家族。项目来源发现层另收录 147 个 GitHub 仓库级 E0 候选；它们与正式目录按仓库 URL 去重后，合计正好 **200 个独立项目来源**。设备与社区层另有 30 条已读具体型号资料的 E1 路线、317 条 E0 线索与 2 条排除记录。统一目录共 547 条记录、451 个不同主来源 URL。它们不是成功实机改造：正式目录 E1 文档与代码证据 50 条、E2 作者实机陈述/演示 3 条，设备层 E1 30 条，E3 独立复现 0 条，本目录亲手测试 0 条。

AI 功能改造 10 条；有明确 AI 辅助开发/配置材料 2 条；AI 周边用途 1 条；传统开源复活基础设施 40 条。不能因为项目可以与大模型结合就把它称为 AI 项目。AI 辅助配置与 AI 编写底层驱动也不是同一种证据。

主要发现：

1. 复用设备常由外部计算机完成新工作。音箱作为音频端点、Kindle 作为显示端点，与在设备内部运行大模型有实质区别。
2. 真正的兼容单位通常是型号、硬件修订、固件、地区的组合。销售名称只适合发现线索。
3. 云替代、系统更新、增加应用、换板与修复物理故障应分开。软件项目不会自动解决电池或存储失效。
4. 旧项目值得保留，但归档、停止维护、镜像迁移与漏洞已修复必须直接展示；未归档不代表每个设备当前仍能部署。
5. 具体问题比泛泛“AI 复活万物”更适合作为内容入口：用户需要知道手里的这台设备是否值得动手。

## 检索与核查方法

以设备和失效原因组合检索 GitHub、官方网站与 X。检索词包括 old hardware reuse、Nest Mini LLM PCB、Kindle dashboard jailbreak、Vector wire-pod、HP Laser macOS Claude driver、router firmware、IP camera local firmware，以及对应中文设备名。

正式目录使用 GitHub 只读 API 取得仓库元数据、README、根许可证与最近 release 列表。新增项目来源发现层通过 GitHub API 与 README 入口确认仓库存在、非 fork，并排除 404、profile 仓库、明显镜像与只读迁移副本；尚未逐项阅读安装、准确型号兼容和恢复资料，因此全部保持 E0。社区线索继续读取项目论坛、作者网站、Codeberg、GitLab、Hackaday、Instructables 与社交平台原帖。逐项阅读适配、部署、失败与恢复片段，保留来源 URL 和核查时间，不重新发布上游教程全文。不存在的旧路径、镜像或跳转不自动视为项目失效，标为 E0 继续核实。

维护状态来自带时间的 API 快照和作者说明。许可证字段优先实际根文件；没有确认的标 UNKNOWN，混合许可不压成一个宽松标签。难度为编辑判断，成本未核价，恢复描述是文档路径而非救砖保证。地区、固件缺少明确材料时保留 null。

正式目录的 X 核查通过浏览器读取 4 条原始帖子正文，涉及 Onju 与 HP 驱动 2 个案例家族；设备图谱另收录 1 条可读取并有项目仓库交叉验证的 GL-AR300M16-Ext 改造线索。部分搜索/抓取入口受限；不把转载、搜索摘要或无法读取的帖子当作原帖核验。视频组件出现不等于看过或验证视频。本轮未记录点赞、浏览量作为成功证据。详见 [X 来源记录](../data/x-research.json)与[设备图谱](../data/device-atlas.json)。

## 作为流量入口的下一步

首屏按“设备 → 用途 → 适配条件”组织，所有条目都有可索引静态详情页。搜索词来自实际设备问题，不生成没有内容的关键词页。

建议先补三类内容：型号对照（如 LX06/OH2P、Kindle 固件边界）；路线比较（桥接/换板/替换系统）；失败与恢复记录（先备份什么，什么条件应停止）。把每篇文章关联到稳定条目 ID 与原始来源。

贡献者通过 issue 提交准确型号、固件、地区、日期、版本、操作来源、成功/失败功能和恢复结果。维护者复核后更新 JSON，重建页面并在变更日志写明证据变化。没有新增证据就不升级等级。仅修改元数据不要刷新“内容核查”日期。

建议人工每月优先检查归档状态、文档迁移和热门条目的服务依赖；每季度审查候选与长期失效链接。这是建议节奏，本项目没有创建定时任务。上线后可以观察搜索收录、issue 质量与用户实际复现；初版没有流量、转化或增长承诺。
