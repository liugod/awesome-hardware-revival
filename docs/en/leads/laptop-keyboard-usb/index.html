Convert an older laptop keyboard into USB

The author reverse-maps an Acer/eMachines MP-09B23U4-6983 keyboard matrix and uses a salvaged STM32 as a USB keyboard controller.

L25 · E0 · Sources reviewed 2026-10-21 · No hands-on hardware tests

DECIDE BEFORE YOU BUILD

Current stage

The author reverse-maps an Acer/eMachines MP-09B23U4-6983 keyboard matrix and uses a salvaged STM32 as a USB keyboard controller.

Practical readiness

The exact model can become a USB keyboard, and the method teaches matrix reverse engineering.

Device fit and limits

Known fit or worth checking

  • The author's Acer MP-09B23U4-6983 / PK130C93A00 model
  • Developers able to probe matrices and solder FPC connections

Not established or unsuitable

  • Plugging an arbitrary laptop keyboard directly into USB
  • Undocumented modules with complex backlight, touch or dedicated controllers

Why this lead is useful

Preserves a good keyboard feel and demonstrates model-specific reverse engineering.

Should you continue?

Investigate further for the same model; treat every other model as a new matrix-mapping project.

Why it remains E0

Laptop matrices, FPCs and connectors are highly nonstandard; this is an author result for one uncommon model.

Next review step

Preserve the full matrix, firmware, connector specification and USB enumeration on another host.

Risk and stop condition

Incorrect voltage can damage the keyboard or controller; map it with current limiting and a meter first.
