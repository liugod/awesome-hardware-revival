Three checks before starting

  • What you need An arm64-v8a or armeabi-v7a device on Android 5.0/API 21 or later with at least 1 GB RAM and 100 MB storage; a running Home Assistant with the ESPHome integration; both on the same LAN, with microphone, overlay, and foreground-service permissions available.Guide 1 ↗ · Guide 2 ↗
  • Rough steps Install the APK and grant the required permissions; add ESPHome in Home Assistant; start the service under Ava's Voice Config, configure the discovered device in HA, select a voice pipeline and wake word, and confirm Connected. If discovery fails, add the device manually using its IP and the actual port shown on Ava's Add this device card.Guide 1 ↗
  • When to stop Stop if the Android version or CPU architecture is unsupported, required permissions cannot be granted, the device and HA are not on the same LAN, or the service's actual port is unreachable. If manual IP-and-port setup still cannot connect, do not continue to optional features.Guide 1 ↗ · Guide 2 ↗

Before you start

  • Do not flash, disassemble, or buy parts without installation and recovery material for the exact model, hardware revision, and firmware.
