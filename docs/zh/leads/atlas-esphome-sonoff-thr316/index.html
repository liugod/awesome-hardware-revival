具体型号资料已读

硬件确认

ESP32；单继电器、三路 LED、按钮和 RJ9 外接 DS18B20 传感器总线。

改造路线

按页面 GPIO 与 RJ9 引脚配置 ESPHome，将温度传感器和继电器组合成 Home Assistant 恒温控制。

可以做到什么

可本地监测温度，并按设定点控制加热负载。

不能扩大解释的边界

示例假设接入 DS18B20；其他温湿度探头和 THR316D 不能直接套用。

恢复与停止条件 默认上电关闭继电器，先验证传感器温度和长短按逻辑，再连接真实负载。
