Exact-model review

  • Hardware ESP32 with 16 A relay, CSE7766 metering, button and two status LEDs.
  • Installation route Remove four screws, use the four-pin programming header, hold the button while powering to enter the bootloader, then flash ESPHome.
  • Expected result Provides local load switching plus current, voltage, power and accumulated-energy readings.
  • Boundary The page covers POWR316 16 A, not POWR316D, POWR320D or revisions with another metering chip.
  • Recovery and stop condition Keep programming fully isolated from mains and preserve stock information; stop when the model suffix differs.
