HK1 Box: boot externally before deciding on Armbian eMMC installation

USER OUTCOME

Treat the HK1 Box in the upstream matrix as an S905X3 TV-box route: boot from USB or microSD, verify the device tree, network, storage, and thermals, then decide whether eMMC installation is justified.

Project overview

When the exact board matches, reuse an idle TV box as a small Debian/Ubuntu-compatible server.

Applicable devices

  • The HK1 Box / Amlogic S905X3 route listed in the ophub support table.
  • Match the board, memory, network, storage, and meson-sm1-hk1box-vontar-x3 device tree on the actual unit; a shared enclosure name is not enough.
  • The linked issue discusses LED and fan GPIO on a particular acrylic fan variant and cannot be generalized to every HK1 Box.

A good fit if

  • You already own an HK1 Box that can be identified on the S905X3 route and will validate it non-destructively first.
  • You need Docker, file services, Home Assistant, or light network services and can maintain a Linux host.

Skip this route if

  • The same-name box has unknown board/network/storage hardware or no stock backup.
  • You need plug-and-play media certification, proven performance, or a zero-maintenance appliance.

Before you start

  • Preserve the stock Android image and boot partitions, plus recovery material for the exact hardware.
  • Boot from USB or microSD first and test boot, networking, storage, display, reboot, and temperature separately.
  • Define the intended service, power, and cooling conditions. A successful boot alone is not a reason to write eMMC.

STOP CONDITIONS

  • Stop when the SoC, board marking, network/storage chip, or device tree cannot be matched.
  • Stop on unstable external boot, missing network/storage, a stopped fan, or unsafe temperature.
  • Do not write eMMC without a stock backup, recovery image, and executable rescue path.

Risk and recovery

Key risks

  • A wrong device tree can remove display, networking, storage visibility, or boot.
  • Writing eMMC replaces the stock system; failure may require partition restoration or reflashing the factory image.
  • KitAgain has not tested power use, performance, DRM, thermals, or long-term stability.

Recovery boundary

  • Use removable-media boot as the first rollback boundary and leave eMMC unchanged until external boot is stable.
  • After eMMC installation, use only backup/restore material matched to the exact board; stop writing when that match is unclear.
