智能插座本地化：先核对芯片、板型与安全条件

OpenBeken、ESPHome 与 Tasmota 都要求准确硬件匹配；同一商品名可能换芯，市电设备还需要合格的断电、隔离与恢复条件。

先识别内部硬件

  • 核对完整型号、地区电气规格、PCB 与主控芯片；外壳和商品页名称不能证明内部硬件相同。
  • OpenBeken 面向其文档列出的 BK7231 等芯片，ESPHome 与 Tasmota 则需匹配对应设备配置或模板。

从型号页决定路线

  • Sonoff S31 与 Shelly Plug S 已有具体型号资料入口，仍需核对当前硬件修订与刷写方式。
  • Athom 与 Kogan 条目目前是型号级线索；在读取芯片、引脚、刷写和恢复资料前，不把它们当作即刷即用固件。
  • 需要保留电量统计时，还要逐项验证电压、电流、功率和累计值；不能从开关成功推断计量准确。

市电安全与验收

  • 断电并确认隔离后才能打开外壳；不在裸露带电状态下探测，也不由本站替代合格的电气判断。
  • 先备份原始 flash 与校准数据，再分别验证开关、断电恢复、网络失效和本地控制。
  • 本站没有新增安全认证、负载测试、计量校准或长期运行结论。
