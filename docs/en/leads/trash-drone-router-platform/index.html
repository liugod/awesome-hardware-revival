Trash Drone Router: networked aircraft from routers and salvaged parts

The author combines old routers, PICs, Wii sensors, IP cameras and motors into a low-cost connected drone platform, with paper, blog and flight-controller links.

L12 · E0 · Sources reviewed 2026-10-21 · No hands-on hardware tests

DECIDE BEFORE YOU BUILD

Current stage

The author combines old routers, PICs, Wii sensors, IP cameras and motors into a low-cost connected drone platform, with paper, blog and flight-controller links.

Practical readiness

Useful for studying a salvaged router as an airborne network node, not as a current ready-to-fly kit.

Device fit and limits

Known fit or worth checking

  • Experiments with older OpenWrt-class routers and replaceable sensors
  • Studying low-cost airborne-network architecture

Not established or unsuitable

  • Copying directly into a safe finished aircraft
  • Outdoor flight without regulatory and failure testing

Why this lead is useful

Records how several waste-device classes can form one system and supports architecture and failure analysis.

Should you continue?

Continue for historical system research; use currently supported flight-control safety paths for real flight.

Why it remains E0

Material is spread across aging links and has not been updated for years; flight safety, radio rules, current code and exact hardware versions are not reconciled.

Next review step

Archive accessible code and papers, then identify one actual airframe, control path and failsafe design.

Risk and stop condition

Propellers, batteries and radio transmission create real hazards; do not fly without failsafes and legal frequencies.
