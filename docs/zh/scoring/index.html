1–5 星复活价值评分

五维加权、半星取整、证据等级独立。

星级回答什么

它用于比较一条复活路线的落地条件，不是兼容保证、安全认证或成功率。E0–E3 单独表示来源证据深度，不参与星级加权，也不设置上限。

五个维度与权重

维度权重
可行性 / 上手难度（越容易分越高）25%
成本（越低分越高）15%
文档与社区活跃度20%
实用价值20%
刷坏与安全风险（风险越低分越高）20%

计算方式

每个维度先给 1–5 分：越容易、成本越低、文档与社区越好、实用价值越高、刷坏与安全风险越低，分数越高。按上表权重求加权平均，再四舍五入到最近的 0.5 星；正好落在中点时向上取整。

未知项怎样处理

缺少可比较事实时使用 3 分中性值，并在 JSON/CSV 的 component_basis 中写明 unknown-neutral 或 unreviewed-neutral。3 分只是计算占位，不表示已经核实为中等。147 个 E0 仓库候选只用已有元数据形成暂定星级，全部标记“待验证”。
