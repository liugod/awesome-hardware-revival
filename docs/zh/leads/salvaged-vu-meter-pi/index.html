适用设备与限制

已知可参考或可继续核查

  • 可独立取出的模拟 VU 表或低压表头
  • 树莓派 PWM/DAC 状态显示

不能视为已支持

  • 未知量程下直接接 3.3V/5V
  • 要求精密快速测量的仪器

缺口、下一步与风险

  • 为什么仍是 E0 表头参数差异很大，项目没有给出每种旧机芯的通用限流值，也未验证长期机械磨损。
  • 下一步核验 测量目标表头满量程电压/电流，做限流、校准和断电归零测试。
  • 风险与停止条件 先把表头从原市电音响电路完全拆离，用低压限流电源测试。
