Hackaday 项目记录了 39 针墨水屏的高压驱动、转接板和 ESP 控制实验，并有一次黑白显示成功日志。

为什么仍是 E0

项目多年未更新，屏幕连接器和波形高度依型号而异；作者也记录过因早期板卡问题损坏屏幕。

下一步核验

核对具体面板编号、PCB 修订、BOM、代码许可证和是否还有可制造文件。

风险与停止条件

驱动包含多路正负高压；错接可能损坏面板，不适合作为通用 Kindle 改造教程。
