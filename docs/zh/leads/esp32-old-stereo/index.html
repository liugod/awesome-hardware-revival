ESP32 蓝牙接收器复用旧音响

作者用 ESP32、VS1053 和外置天线让旧音响接收手机蓝牙音频，并链接两套实现代码与演示。

L10 · E0 · 资料核查 2026-10-21 · 未进行实机测试

先判断是否值得继续

当前阶段

作者标记为完成，并给出两套源码、硬件组成和演示；KitAgain 尚未测量音质、延迟、噪声和稳定性。

现在能用到什么程度

可把手机 A2DP 音频通过 ESP32+VS1053 输出到旧音响线路输入；更适合做外置接收盒。

适用设备与不能这样用的情况

已知可参考或可继续核查

  • ESP32-WROOM-32U、外置天线与通用 VS1053 MP3 板
  • 普通 ESP32 加 Adafruit VS1053 breakout 的作者路线
  • 有 AUX、Line In 等线路电平输入的旧音响

不能视为已支持

  • 只有喇叭端子、没有线路输入的无源音箱
  • ESP32 直接驱动大功率扬声器
  • 低延迟视频同步、发烧级音质或所有蓝牙编码格式

对用户有什么价值

能以可回退的外置盒方式给旧功放增加手机蓝牙输入，元件和源码路线清楚。

是否值得继续跟进

音响有线路输入且能装配低压模块时继续；要求高保真、超低延迟或必须拆市电机箱时选成品接收器。

为什么仍是 E0

KitAgain 尚未核对代码许可证、音频质量、延迟、供电噪声、不同功放输入和长期维护。

下一步核验

核对两种板卡的引脚/BOM/许可证，并在带线路输入的旧音响上做可回退测试。

风险与停止条件

优先使用外部低压线路输入；涉及市电机内改线时需要额外隔离和电气安全评估。
