EXACT-MODEL SOURCE REVIEWED

Hardware

ESP8266 with relay, HLW8012 power metering, NTC temperature and external switch input.

Installation route

Apply the documented ESPHome GPIO configuration and recalibrate power and temperature against the physical unit.

Expected result

Enables local load control, daily energy tracking and over-temperature actions.

Boundary

Example calibration points are not certified values for every Shelly 1PM.
