DECIDE BEFORE YOU BUILD

Current stage

The project uses a Raspberry Pi with spare monitors and accepts static documents or art through SCP, shared folders, a web page or WebSocket.

Practical readiness

The architecture and transfer methods are clear enough for a workbench prototype, while release completeness is unclear.

Device fit and limits

Known fit or worth checking

  • Spare LCD monitors with standard video input
  • A Raspberry Pi or similar display-capable host

Not established or unsuitable

  • Bare LCD panels without controllers
  • Users needing a maintained one-click deployment

Why this lead is useful

Turns a general monitor into a dedicated reference display without pointer or window-management friction.

Should you continue?

Worth trying if you can maintain Linux boot and transfer scripts; otherwise use maintained signage software.

Why it remains E0

The page still says a release is coming and has been quiet for years; install artifacts, maintenance and unattended recovery are unverified.

Next review step

Confirm source, setup steps, boot recovery and current browser/image dependencies.

Risk and stop condition

Do not open CRTs or old monitor power supplies; prefer complete displays with standard video inputs.
