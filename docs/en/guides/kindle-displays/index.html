Old Kindle displays: choose the content, then check firmware

Home Assistant, WHOOP and desktop usage dashboards need different external services. An e-ink display endpoint is not evidence of AI running locally.

Check the device you own

  • Record the exact model and firmware, then check its jailbreak guide. WinterBreak is a prerequisite tool, not a finished dashboard.
  • A Kindle 4 Home Assistant example does not establish support for every Paperwhite. The WHOOP author's verified scope is PW2 / 5.10.3.
  • Back up device files and configuration. Removing scripts and undoing a jailbreak are separate steps.

Choose by content

  • Already use Home Assistant: compare server-side screenshots with Kindle display, checking page permissions, rendering and retrieval separately.
  • Already have WHOOP data: check account/API, KUAL/linkss and wake behavior. One completed cycle does not prove weeks of battery life.
  • Desktop AI usage: Kindle Dashboard needs a Windows 10/11 host and SSH/FBInk. Displaying usage is not running a model.
  • Switchable content: Kindle Carousel documents Kindle 3 / 4 NT. Continuous button listening affects battery life.

Minimum checks before continuous use

  • Display a correctly sized image manually before scheduling refresh and wake.
  • Simulate disconnection, expired authentication and stale data so outdated information is not silently presented.
  • Record several days of power use, failed refreshes and recovery. Hosts and service costs are not priced. Linked project pages preserve original evidence; this guide adds no hardware testing.
