An old mini PC at home: automation, storage or media?

Choose one clear job, then check boot mode, storage health and backups. Installing an OS does not add computing power.

Home automation

  • HAOS suits a dedicated x86-64 UEFI host. The official Generic route requires Secure Boot disabled and checks for 512n/512e storage; a 64-bit CPU alone is not enough.
  • Writing the image overwrites the target disk. Connect a real device and practice backup restoration before long-term use.

LAN storage

  • OpenMediaVault needs a plan for the OS disk, data disks and an independent backup. Old-disk health is a separate issue.
  • The README says it needs exclusive control over OS configuration. Do not treat it as an ordinary app to containerize or install alongside a desktop. RAID does not replace backups.

Light services, media or games

  • For DietPi, check available images, architecture and RAM. Not every old board is supported.
  • LibreELEC is a dedicated Kodi OS requiring a matching current image. Verify DRM services separately.
  • Batocera offers external boot options; internal installation still needs backups. Hardware limits performance, and the OS grants no game copyright permissions.

What to record when choosing

  • Boot mode, disk logical sectors, networking/peripheral support and behavior after reboot.
  • Power, noise, disks and accessories depend on the actual device. This catalog has no measurements or prices.
  • Use external media or backups to reduce switching costs. The linked project pages provide original documentation and route-specific limits.
