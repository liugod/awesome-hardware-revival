是否值得继续

  • 当前阶段 v2 硬件曾正常产生电压，并在特定备用屏上得到黑白输出；灰阶和通用适配未完成。
  • 现在能用到什么程度 对能识别 39 针面板、会贴片焊接并理解正负高压的开发者有复刻价值；普通 Kindle 用户不能直接套用。
  • 用户价值 电源轨、连接器、PCB/代码和失败日志能减少逆向工作，但它不是即插即用产品。
  • 继续跟进建议 能读取面板编号、测量高压并自行审查 PCB 时继续；普通副屏需求应选完整方案。

适用设备与限制

已知可参考或可继续核查

  • 项目实际使用的 39 针拆机电子纸面板及相同电气规格面板
  • ESP8266 或 STM32 控制实验，但需重查时序、RAM 和 PCB 修订
  • 需要 Gerber、PCB 和驱动源码继续研究的开发者

不能视为已支持

  • 假设所有 Kindle 6 英寸屏或所有 39 针屏都兼容
  • 不检查二极管方向、FPC 和修订就直接下单
  • 完整灰阶、成品外壳或长期稳定显示

缺口、下一步与风险

  • 为什么仍是 E0 项目多年未更新，屏幕连接器和波形高度依型号而异；作者也记录过因早期板卡问题损坏屏幕。
  • 下一步核验 核对具体面板编号、PCB 修订、BOM、代码许可证和是否还有可制造文件。
  • 风险与停止条件 驱动包含多路正负高压；错接可能损坏面板，不适合作为通用 Kindle 改造教程。
