Exact-model review

  • Hardware ESP32-C3, 8 MB flash, four switch inputs, reset button, status LED and NTC.
  • Installation route Use the same programming interface as Shelly Plus i4, then run ESPHome with the documented Gen3 pins.
  • Expected result Feeds four wall-switch actions and temperature diagnostics into local automation.
  • Boundary Gen3 pins differ from the older Plus i4 and configurations are not interchangeable.
  • Recovery and stop condition Confirm the enclosure and PCB are Gen3; power down and re-check when input numbering or temperature is wrong.
