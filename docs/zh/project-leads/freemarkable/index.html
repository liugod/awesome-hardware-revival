开始前的三点

  • 你需要什么 freeMarkable 的已核前提：GUI 会自动识别 reMarkable 1/2/Paper Pro 架构并执行安装，但仍要求 Python 3.10、SSH、USB/Wi-Fi 和联网下载。教程 1 ↗
  • 大致步骤 按链接上游安装/配置路径执行 freeMarkable；本次有证据的目标仅为：可安装 XOVI、AppLoad 与 KOReader，并覆盖三代 reMarkable，能把封闭设备转为可运行第三方应用的终端。教程 1 ↗
  • 何时停止 freeMarkable：若无法接受以下风险或没有对应回退路径就停止：上游明确在修改前自动备份，提供备份恢复、完整卸载与错误回退；仍要求设备在安装期间保持充足电量。教程 1 ↗
