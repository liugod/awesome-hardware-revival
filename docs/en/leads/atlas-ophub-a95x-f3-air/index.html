Decide before you build

  • Current stage The goal is to convert A95X F3 Air from an Android TV box into a small Armbian host for Docker, file services, Home Assistant or light network services.
  • Practical readiness A maintainer-listed starting point for image and device-tree selection; the physical board still needs confirmation.
  • User value The Chinese maintainer document maps box models to SoC/image families so obvious mismatches can be rejected early.
  • Follow-up recommendation Continue only after stable external boot with working network and storage; stop when the device tree or recovery image is unknown.

Device fit and limits

Known fit or worth checking

  • A95X F3 Air units with a matching SoC and board
  • Users willing to validate non-destructively from USB or microSD first

Not established or unsuitable

  • Same-name boxes with unknown board, Wi-Fi or storage chips
  • Devices headed for direct eMMC installation without a stock backup

Gaps, next step, and risk

  • Why it remains E0 The maintainer device table lists the model and SoC family, but identical product names may hide different boards, memory, Wi-Fi or storage. No unit was tested here.
  • Next review step Verify the SoC, board marking, memory and network chip. Boot from USB or microSD and test networking and storage before considering eMMC installation.
  • Risk and stop condition Back up the stock Android and boot partitions. A wrong device tree may lose display, network or boot; do not overwrite eMMC before external-media testing.
