Three checks before starting

  • What you need A compatible amd64 small host, at least two reliable NICs, an installer USB, a configuration backup, and local console access.Guide 1 ↗ · Guide 2 ↗
  • Rough steps Check hardware and throughput, verify the image, validate NICs and configuration with Live/Importer first, then select the target disk for installation.Guide 1 ↗ · Guide 2 ↗
  • When to stop Stop if the host is not amd64, a critical NIC lacks FreeBSD support, local access is unavailable, or the disk that will be erased cannot be identified with certainty.Guide 1 ↗ · Guide 2 ↗
