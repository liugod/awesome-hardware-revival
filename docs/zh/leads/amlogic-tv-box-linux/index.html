先判断是否值得继续

当前阶段

Armbian 论坛 FAQ 明确把电视盒路线定位为社区实验，建议更适合无头 Linux 服务器而非桌面替代。

现在能用到什么程度

部分盒子可从 SD/USB 启动成为低成本服务器，但外设常不完整。

适用设备与不能这样用的情况

已知可参考或可继续核查

  • 论坛有同板报告的 Amlogic 盒子
  • 只需以太网、USB 和无头服务的实验

不能视为已支持

  • 把零售型号当作统一硬件
  • 要求官方更新、完整 Wi-Fi/蓝牙/视频加速的主力机

对用户有什么价值

论坛把风险和合理用途说得很清楚，可避免把盒子误当稳定 SBC。

是否值得继续跟进

有串口/备份并接受试验性质时继续；重要服务选正式支持 SBC。

为什么仍是 E0

相同外壳可能使用不同 eMMC/NAND、Wi-Fi 和板卡；并非 Armbian 官方支持设备。

下一步核验

开壳确认 SoC、存储和板号，保存 Android 固件，并为一个精确型号核对 DTB 与启动链。

风险与停止条件

错误 DTB 或写入 eMMC 可变砖；散热和廉价电源也需长期测试。
