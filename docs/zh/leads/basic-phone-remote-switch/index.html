适用设备与限制

已知可参考或可继续核查

  • 带振动电机且仍可接入当地网络的旧功能机
  • 低压、可安全失败的测试负载

不能视为已支持

  • 当地已关闭对应蜂窝制式
  • 未经电气隔离的水泵和市电设备

缺口、下一步与风险

  • 为什么仍是 E0 只读到作者完成记录；白名单、防误触、2G/3G 退网、继电器隔离和长期可靠性未系统验证。
  • 下一步核验 先核对当地蜂窝网络、呼叫白名单、低压模拟负载和误触测试。
  • 风险与停止条件 不能直接用随意继电器控制水泵或市电；垃圾短信和误拨也可能触发。
