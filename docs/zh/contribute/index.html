贡献一份可靠记录

成功、失败和不支持条件，都值得保留。

提交什么

  • 项目 ID、准确型号、硬件修订、固件与地区
  • 上游版本、操作日期及原始步骤链接
  • 成功与失败功能、恢复结果及可核验材料
  • 不要公开设备唯一序列号、账号、令牌或密钥

资料如何进入目录

提交后先标为待核验。编辑检查来源与型号条件，再同步中英文；没有独立证据就不升级为 E3。失败记录同样有价值。
