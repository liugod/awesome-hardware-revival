版本与核查状态

  • 当前版本 v1.19.0
  • 核查日期 正式目录 2026-10-20；设备图谱 2026-10-22；项目来源发现层 2026-10-24。
  • 实机状态 未进行实机测试。条目收录不等于兼容认证、安全认证或成功保证。

证据等级

  • E0 只确认条目和来源的关联，还要核对准确型号、安装与恢复。
  • E1 已读源码、部署文档或设备兼容资料。
  • E2 有作者的实机陈述或演示。
  • E3 有已核验的独立复现。

证据等级与复活星级独立；它不参与加权，也不限制星级上限。

复活星级

维度权重
可行性 / 上手难度（越容易分越高）25%
成本（越低分越高）15%

实用价值20%

  • 每个有可核验来源的维度给 1–5 分；没有证据时保存为 null，不用中性 3 分补位。
  • 只在已取证维度之间把原权重按比例重新归一到 100%。
  • 至少 3 个维度有证据才计算总分；否则显示“待评分”，并排在已评分条目之后。
  • 加权平均四舍五入到最近的 0.5 星，正好落在中点时向上取整。

贡献指南

  • 写明项目 ID、准确型号、硬件修订、固件和地区。
  • 附上源版本、操作日期和原始步骤链接。
  • 保留成功、失败、恢复结果和可核验材料。
  • 不要公开唯一序列号、账号、令牌或密钥。
