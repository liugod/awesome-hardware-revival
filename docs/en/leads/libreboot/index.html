Decide before you build

  • Current stage The upstream project and documentation are substantial, with explicit supported devices and install routes; KitAgain has not normalized every board.
  • Practical readiness Exact boards in the current official list can enter installation assessment. Some support internal flashing; others require external hardware.
  • User value The support list can support a real board, flashing and recovery decision. Firmware-writing risk is the main issue.
  • Follow-up recommendation Continue if you can identify the board, back up the complete flash and prepare recovery hardware; stop if you cannot accept a non-booting machine.

Device fit and limits

Known fit or worth checking

  • Official ThinkPad X200/T400/T500/W500/R400/R500 routes
  • Official X220/X220T/T420/T420s/T520 and X230/T430/T530/W530/X230T routes
  • Exact Chromebook, server, desktop and workstation boards in the current list

Not established or unsuitable

  • Board revisions absent from the current list despite a similar family name
  • Removed boards or devices with only old instructions and no current ROM
  • Machines whose flash chip, backup and external recovery path cannot be confirmed

Gaps, next step, and risk

  • Why it remains E0 The upstream material is substantial, but KitAgain has not yet converted supported boards, internal/external flashing, license scope and recovery equipment into a reviewed catalog entry.
  • Next review step Start with one exact ThinkPad or Chromebook board and verify its ROM, flashing method, backup and rollback.
  • Risk and stop condition This writes boot firmware. Upstream requires a flash backup and warns that incorrect steps can leave the machine unable to boot.
