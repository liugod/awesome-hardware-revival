Shelly 1 Gen4: convert it to a local ESPHome device

The goal is clear: use an ESPHome configuration for Shelly 1 Gen4, reduce dependence on the vendor cloud and connect it to a local system such as Home Assistant.

EXACT-MODEL SOURCE REVIEWED

Hardware

ESP32-C6, 8 MB flash and an isolated dry-contact relay; standard 1 Gen4 has no power metering.

Installation route

Upstream provides ESPHome configuration for the relay, external input, device button, status LED and internal temperature.

Expected result

Suited to dry-contact control of garage doors, boilers and separate AC/DC circuits.

Boundary

Do not confuse Shelly 1 Gen4 with the power-metering Shelly 1PM Gen4.
