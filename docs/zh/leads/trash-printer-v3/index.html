先判断是否值得继续

当前阶段

项目尝试用本地废塑料和从旧 3D 打印机回收的运动件，构建易制造的塑料再利用打印系统。

现在能用到什么程度

适合有制作空间的人研究旧打印机零件和废塑料再利用，不是桌面即插即用设备。

适用设备与不能这样用的情况

已知可参考或可继续核查

  • 可回收步进电机、导轨等部件的旧 3D 打印机
  • 能分类清洁塑料并加工框架的工作室

不能视为已支持

  • 混合或来源不明塑料直接熔融
  • 家庭无人看护运行

对用户有什么价值

同时处理旧机器部件和废塑料，且作者强调低工具门槛。

是否值得继续跟进

有通风、防火和机械制造能力时研究；普通打印需求优先修复现有打印机。

为什么仍是 E0

需要自行制造机械结构和处理塑料；成品质量、材料污染、挤出稳定性和完整成本未由 KitAgain 核验。

下一步核验

核对最新图纸、BOM、进料流程、温度范围和一套完整打印验收。

风险与停止条件

塑料加热、粉尘、切削和高功率加热器需要通风、温控和防火保护。
