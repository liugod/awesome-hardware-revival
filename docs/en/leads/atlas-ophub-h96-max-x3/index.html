H96 Max X3: turn the TV box into an Armbian server

The goal is to convert H96 Max X3 from an Android TV box into a small Armbian host for Docker, file services, Home Assistant or light network services.

Hardware

H96 Max X3 listed by ophub as S905X3 on the stable-kernel route.

Installation route

Test from SD/USB with the exact DTB and do not equate successful external boot with safe eMMC installation.

Expected result

Can run an Armbian server, but kernel and eMMC combinations need version-specific testing.

Boundary

Historical issue 1250 reports 6.1.22 booting from SD but black-screening on eMMC while 5.15.105 worked.
