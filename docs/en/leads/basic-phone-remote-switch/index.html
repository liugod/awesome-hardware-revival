Use an old feature phone as a call-triggered remote switch

The author reads call/SMS activity from an old Nokia-class phone's vibration-motor pads, then lets an Arduino and relay switch an external load.

L18 · E0 · Sources reviewed 2026-10-21 · No hands-on hardware tests

DECIDE BEFORE YOU BUILD

Current stage

The author reads call/SMS activity from an old Nokia-class phone's vibration-motor pads, then lets an Arduino and relay switch an external load.

Practical readiness

A low-voltage remote-trigger experiment where a compatible cellular network still operates.

Device fit and limits

Known fit or worth checking

  • Feature phones with a vibration motor and local network service
  • Low-voltage loads that fail safely

Not established or unsuitable

  • Regions where the required cellular generation is shut down
  • Pumps or mains devices without engineered isolation

Why this lead is useful

Demonstrates reuse of an old phone's communication path without mobile data.

Should you continue?

Continue only with low-voltage tests and strict allowlisting; use industrial controls for critical loads.

Why it remains E0

Only the author build is reviewed; allowlisting, false triggers, 2G/3G shutdown, relay isolation and long-term reliability remain unresolved.

Next review step

First verify local cellular service, call allowlisting, a low-voltage dummy load and false-trigger tests.

Risk and stop condition

Do not use an arbitrary relay directly for pumps or mains; spam messages and accidental calls can trigger it.
